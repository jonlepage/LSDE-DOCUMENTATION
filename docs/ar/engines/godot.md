# Godot

يتكامل LSDE مع **Godot 4** لإدارة وترجمة حواراتك، مع دعم أصلي لـ GDScript و C# (Mono).

## التكامل {#integration}
يستخدم Godot ملفات CSV أو JSON للتوطين عبر نظام `TranslationServer` الخاص به.
يمكن لـ LSDE استيراد وتصدير هذه التنسيقات لسير عمل سلس بين الأداتين.

سير العمل:
- **الاستيراد** — استورد ملفات ترجمة Godot (CSV أو JSON) إلى LSDE عبر الاستيراد الذكي (Smart Import).
- **التحرير** — ترجم وحرر بمساعدة LLM والبيانات الوصفية (metadata) والمدقق الإملائي.
- **التصدير** — أعد تصدير الملفات الموطّنة مباشرةً إلى مجلد مشروع Godot الخاص بك.

## توليد الكود {#code-generation}
يقوم LSDE تلقائيًا بتوليد فئات وصول مُحددة النوع (typed access classes) بلغتين:
- **GDScript** — فئات Godot الأصلية مع الإكمال التلقائي في محرر Godot.
- **C# (Mono)** — لمشاريع Godot التي تستخدم بيئة تشغيل .NET.

تتيح هذه الفئات الوصول إلى مفاتيح حواراتك مع التحقق من النوع، مما يجنب أخطاء السلاسل النصية المكتوبة يدويًا.

## نصائح {#tips}
- يقوم Godot بتحميل الترجمات عبر `TranslationServer.set_locale()` — ملفاتك التي تم تصديرها بواسطة LSDE متوافقة بشكل مباشر.
- ضع ملف `.lsde` في جذر مشروع Godot الخاص بك للتحكم في الإصدارات (Git).
- قم بتكوين التصدير التلقائي عند الحفظ في LSDE لمزامنة تعديلاتك باستمرار مع Godot.
- استخدم `tr()` في نصوص GDScript البرمجية الخاصة بك للوصول إلى مفاتيح الترجمة المصدرة.
