# Runtime (LSDEDE)

يقوم محرك التنفيذ متعدد الرنتايم (multi-runtime) بتحميل وتشغيل المخططات (blueprints) المصدرة من المحرر.
متوفر بلغات TypeScript و C# و C++ و GDScript، ويتكامل أصلاً مع أي محرك ألعاب أو إطار عمل.
تعتمد البنية المعمارية على الـ callbacks، وهي خالية من التبعيات الخارجية ومستقلة عن إطار العمل.
