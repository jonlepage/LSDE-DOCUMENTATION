# توطين

تتيح لك هذه الوحدة الإلزامية تكوين اللغات ومساحات الأسماء لمشروعك.
لديك خيار استخدام الاستيراد الذكي أو تكوين خدمة اللغات يدويًا.

::: tip ملاحظة
يدعم LSDE رموز ISO 639-1 أو تركيبات ISO 639-1 - ISO 3166-1. [لمزيد من التفاصيل حول المواصفات، انقر هنا](/ar/getting-started/introduction#i18n-key-convention)
:::

## الواجهة {#interface}
<DocImage src="/doc/lsde/doc-lsde-ui-localisations.webp" />

توفر الواجهة الأقسام التالية:
0. **الاستيراد الذكي** (اختياري)
قم باستيراد بنية مجلدات موجودة مسبقًا، منظمة بالطريقة التالية:
`../folder/lang/namespace.json` => `../locales/en/main.json`

### تكوين اللغات {#setup-languages}
- **تكوين رموز `ISO 639-1` و `ISO 3166-1`**
يمكن دمج رموز اللغة وفقًا لمواصفات اثنين، على سبيل المثال: `en` أو `en-US`، `en-GB`.
تتوافق هذه الرموز `ISO 639-1 - ISO 3166-1` مع اللغة متبوعة بموقعها الجغرافي.

**يتيح هذا القسم ما يلي:**
1. إضافة/حذف لغات
يفتح مربع حوار جديد يمكنك فيه استخدام مدير للعثور على لغات المشروع و/أو حذفها.
2. تحديد اللغة الأساسية
تُستخدم هذه اللغة كمصدر في بعض المهام وهي إلزامية للعمل مع البرنامج.
4. عرض أو حذف أو إعادة ترتيب اللغات بالترتيب المطلوب.

::: tip ملاحظة
(هذا هو ترتيب العرض في المحرر.) هذه هي اللغة الأساسية للمشروع.
:::

### مساحات الأسماء {#namespace}
3. هذا هو المكان لإنشاء مساحات الأسماء.
تمثل مساحة الاسم ببساطة **اسم ملف يحتوي على المفاتيح**. الأمر بهذه البساطة.
مثال: `locales/en-GB/main.json`. هنا، ستكون مساحة الاسم `main` وستكون مفاتيح الملف ذات مسارات نسبية.

::: tip ملاحظة
يمكنك إعادة تعريف مجلدات مساحات الأسماء أو حذفها.
:::
