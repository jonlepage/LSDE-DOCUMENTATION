# ورقة الميزات

يوفر إصدار Beta العام تحسينات كبرى في تجربة المستخدم (UX) والميزات لدعم أي نوع من المشاريع. 
فيما يلي ملخص للميزات (Cheat Sheet):

## عام {#general}
- واجهة مدمجة للغاية، عصرية ومريحة (ergonomic).
- الواجهة مترجمة بالكامل لـ 10 لغات: fr, en, es, de, it, pl, ja, ko, zh, ru.
- تبديل سريع للواجهة بين لغتين مفضلتين عبر `[F1]`.
- نظام تخطيط (layout) مرن مع نوافذ قابلة للإرساء (dockable) (مثالي للشاشات المتعددة).
- وضع ملء الشاشة لجميع النوافذ.
- تلميحات مساعدة (Infobulles) على جميع الأزرار عند تمرير الماوس.
- سهولة الوصول (Accessibility): خيارات مخصصة لعمى الألوان واضطرابات الرؤية.
- اختصارات لوحة المفاتيح للإجراءات السريعة حسب السياق.
- عدة أوضاع Zen لتعزيز التركيز أثناء الكتابة.
- إحصائيات المشروع في الوقت الفعلي: keys، كلمات، رموز، tokens، ضربات المفاتيح، التحديدات.
- إنشاء سريع للمشاريع بشكل موجه ومعد مسبقاً بنقرة واحدة.
- ملفات مشاريع `.lsde` بتنسيق JSON متوافقة مع إصدارات (Git) وسهلة المشاركة.
- دعم النظام (OS) للأيقونات ولفتح المشاريع بامتداد `.lsde`.
- خيار إعادة الفتح التلقائي لآخر مشروع تم استخدامه.
- History للمشاريع الأخيرة المفتوحة.
- كشف الإغلاق غير المتوقع مع استعادة الجلسة.
- استيراد/تصدير فردي لملف تعريف التكوين العام لـ LSDE.
- تفعيل/تعطيل وتغيير نموذج LLM بنقرة واحدة.
- دعم LLM native للطوارئ (fallback) مجاني ومجهول، بدون حساب أو مفتاح API.
- دعم copilots LLM: Claude, DeepSeek, Gemini, GPT, Mistral, Ollama, ElevenLabs...
- دعم LLM المحلية عبر `localhost`.
- مساعد LLM مدمج مدرب على الوثائق لإرشادك.
- قائمة مساعدة LLM في حقول التكوين: مساعدة، ملء، تحسين، ترجمة.
- تشخيص وإدارة الأخطاء والتحذيرات الداخلية.
- وثائق كاملة لـ LSDE و i18n متاحة عبر الإنترنت.
- دعم فتح الروابط خارجياً (المتصفح) أو داخلياً (LSDE).
- إعدادات مسبقة لـ: Unity, Godot, RPG Maker, Unreal Engine, GameMaker, Construct3, Cocos2d, Phaser, Babylon.js, SugarCube, NovelStudio...
- مدير سياقات i18n قابل للتخصيص: الجمع، الجنس، القيم المنطقية، إلخ.

## المطور {#dev}
- نظام تحليل قاعدة الكود للربط التلقائي للمفاتيح (keys).
- ماسح RAW لتحديد النصوص الخام التي قد تحتاج إلى مفاتيح i18n.
- RegEx معدة مسبقاً وقابلة للتخصيص لمحركات الألعاب الخاصة.
- دعم المفاتيح الديناميكية (مثل: `game:.scenes.${index}.events.1`).
- إنشاء تلقائي للمفاتيح مع كشف السياق والنص الافتراضي.
- فلتر عرض للمفاتيح المكتشفة ولكن لم يتم إنشاؤها بعد.
- نقر مزدوج لفتح IDE في الموقع الدقيق للمفتاح في كود المصدر.
- التحكم في عدد أسطر كود المصدر المعروضة.
- ثيمات عرض لكود المصدر.
- كشف ومعاينة عدم المزامنة الخارجية لملفات i18n في الوقت الفعلي.
- خيار المزامنة اليدوية بنقرة واحدة.

## الشجرة {#tree}
- أوضاع عرض متعددة: شجرية، قائمة مسطحة (مع أو بدون المسار الكامل)، الترجمات المفقودة، مفاتيح بدون مرجع، مع صوت أو مع مهمة قيد التنفيذ.
- بحث بواسطة المفتاح (key) أو المحتوى المرتبط.
- تصميم مجلدات namespaces (root) محسن لتحديد سريع.
- عرض عدد المجلدات الفرعية عند التحديد.
- إنشاء ذكي لمفاتيح i18n مع زيادة تلقائية حسب التحديدات.
- قائمة سياقية كاملة عبر النقر بزر الماوس الأيمن.
- تحديد متعدد باستخدام `Ctrl+clic`.
- دعم السحب والإفلات (Drag & Drop).
- علامات (Tags) سياقية على كل عنصر: جمع، جنس، صوت، غير مكتمل، غير معروف في الكود، إلخ.
- مهام الدفعات (batch) عبر القائمة السياقية للتكرار على المجلدات الفرعية.

## LLM {#LLM}
- مدير النماذج المفضلة.
- إدارة آمنة لمفاتيح API.
- إمكانية تسجيل عدة مفاتيح API مع تدوير تلقائي (auto-roll) في حالة حدوث أخطاء.
- إدارة وتخصيص المهام الأصلية: التعليمات والقواعد المرسلة إلى LLM.

## التحرير / التأليف {#editing}
- تخصيص الثيم وطباعة النصوص: الخطوط، التباعد، ارتفاع السطر، الألوان ودعم RTL.
- محرك رندر نصوص قابل للتخصيص بنسبة 100%: متغيرات، ألوان، روابط، تلميحات.
- فلترة اللغات والسياقات المراد عرضها.
- بحث، استبدال وتنقل نصي مع دعم RegEx.
- قائمة مهام لمعالجة كل حوار: ترجمة، تصحيح، إعادة صياغة، ضبط الطول، تكملة النص.
- مدقق إملائي LLM قابل للتكوين في الوقت الفعلي.
- شريط إجراءات سريعة: تنقل، إدارة الرندر، إنشاء سياقات أو مفاتيح.
- خيار وضع الفقرة عبر سطر فارغ مزدوج.
- حذف سريع للسطر (سلوك IDE).
- قائمة سياقية عند تحديد النص.
- مدير wrappers قابل للتخصيص لتأطير النص المحدد.
- Wrappers تزايدية وعكسية حسب عدد التفاعلات.
- نظام التحقق (Validation): كشف التغييرات، ترجمات يجب إعادة التحقق منها أو تجاهلها.
- مقارنة التعديلات وتحسين النتائج أثناء المهمة.
- حفظ التكوينات السريعة لكل نوع من المهام.
- دعم نماذج SAD/MAD (Single/Multi Actor Per Dialog).
- مدير صوت (audio) لكل شخصية ولكل سلسلة نصية.
- معاينة البيانات الوصفية (Metadata): صور، ملاحظات، سياقات LLM، شخصيات، أصوات، أيقونات.
- عرض المتغيرات التابعة والمراجع النصية.
