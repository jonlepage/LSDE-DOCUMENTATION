# MCP Bridge

يسمح خادم MCP Bridge للأدوات وعوامل الذكاء الاصطناعي الخارجية بالتفاعل مع المحرر عبر بروتوكول MCP القياسي (Model Context Protocol).

## ما هو MCP؟ {#what-is-mcp}
MCP هو بروتوكول مفتوح يسمح لنماذج اللغة وعوامل الذكاء الاصطناعي بالتواصل مع التطبيقات الخارجية.
يمكن لبيئة التطوير المتكاملة الخاصة بك (IDE) (مثل VS Code، Cursor، إلخ) الاتصال تلقائيًا بخادم MCP لإثراء قدرات مساعد الذكاء الاصطناعي الخاص بك.
يتم الاتصال عبر ملف تكوين `.mcp.json` موجود في المجلد الرئيسي لمشروعك — لا يلزم تثبيت يدوي.

## الإعدادات {#configuration}
أنشئ أو عدّل ملف `.mcp.json` في المجلد الرئيسي لمشروعك لإضافة الخادم إليه:
```json
{
	"mcpServers": {
		"lsde": {
			"command": "npx",
			"args": ["-y", "@lsde/mcp-server@latest"],
			"env": {
				"LSDE_MCP_PORT": "9225"
			}
		}
	}
}
```
بمجرد وضع هذا الملف، أعد تشغيل بيئة التطوير المتكاملة الخاصة بك (IDE) (أو إضافة الذكاء الاصطناعي) لاكتشاف الخادم.
العملية مؤتمتة بالكامل: يتم تنزيل الحزمة عبر `npx` ويتم تشغيل الخادم في الخلفية.

[حزمة npm: @lsde/mcp-server](https://www.npmjs.com/package/@lsde/mcp-server)

## القدرات {#capabilities}
يسمح خادم MCP Bridge للعوامل الخارجية بما يلي:
- **قراءة بنية المشروع** — شجرة المشاهد، الكتل، الاتصالات، والبيانات الوصفية.
- **الاطلاع على العقد** — الوصول إلى النص وخصائص أي عقدة في الرسم البياني.
- **إدارة المتغيرات** — قراءة المتغيرات والقواميس الخاصة بالمشروع والتفاعل معها.
- **تشغيل إنشاء المشاهد** — إنشاء مشاهد جديدة عبر أوامر منظمة.
- **اقتراح تعديلات** — تقديم تعديلات نصية أو هيكلية للمصادقة عليها.

## حالات الاستخدام {#use-cases}
- **Claude Code / Cursor** — ادمج المحرر في سير عمل التطوير الخاص بك المدعوم بالذكاء الاصطناعي.
- **خطوط الأنابيب المؤتمتة** — اربط المحرر ببرامج البناء أو CI/CD الخاصة بك.
- **عوامل ضمان الجودة (QA)** — تحقق تلقائيًا من الاتساق السردي لحواراتك.
- **أدوات مخصصة** — أنشئ عمليات التكامل الخاصة بك عبر البروتوكول القياسي.

## التوفر {#availability}
يتوفر MCP Bridge في خطط **المحترفين** و **الشركات/التعليم**.
