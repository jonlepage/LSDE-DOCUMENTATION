# 機能シート

パブリックベータ版は、あらゆる種類のプロジェクトをサポートするために、ユーザーエクスペリエンス（UX）と機能面で大幅な改善をもたらします。
機能の概要（チートシート）は以下の通りです：

## 一般 {#general}
- 非常にコンパクトでモダン、人間工学に基づいたインターフェース。
- 10言語（fr, en, es, de, it, pl, ja, ko, zh, ru）に完全翻訳されたインターフェース。
- `[F1]`キーによる、お気に入り2言語間のインターフェースのクイック切り替え。
- ドッキング可能なウィンドウを備えたモジュール式レイアウトシステム（マルチモニターに最適）。
- すべてのウィンドウでの全画面表示モード。
- ホバー時にすべてのボタンにヘルプのヒント（ツールチップ）を表示。
- アクセシビリティ：色覚特性や視覚障害向けの専用オプション。
- 文脈に応じたクイックアクション用ショートカットキー。
- 執筆中の集中力を高める複数のZenモード。
- プロジェクトのリアルタイム統計：キー、単語、文字、トークン、キーストローク、選択範囲。
- ワンクリックで設定済みのガイド付きプロジェクト作成。
- バージョン管理（Git）に対応し、共有が容易なJSON形式のプロジェクトファイル`.lsde`。
- アイコンのOSサポートおよび`.lsde`拡張子でのプロジェクト起動。
- 最後に使用したプロジェクトの自動再開オプション。
- 最近開いたプロジェクトの履歴。
- 予期しない終了の検出とセッション復元。
- LSDEのグローバル設定プロファイルの個別インポート/エクスポート。
- ワンクリックでのLLMモデルの有効化/無効化および変更。
- アカウントやAPIキー不要、無料で匿名のネイティブフォールバックLLMをサポート。
- LLMコパイロットのサポート：Claude, DeepSeek, Gemini, GPT, Mistral, Ollama, ElevenLabs...
- `localhost`経由のローカルLLMをサポート。
- 操作ガイドのための、ドキュメントを学習済みの内蔵LLMアシスタント。
- 設定フィールドのLLMアシスタントメニュー：ヘルプ、入力補完、改善、翻訳。
- 内部エラーおよび警告の診断と管理。
- オンラインで利用可能なLSDEおよびi18nの完全なドキュメント。
- 外部リンク（ブラウザ）または内部リンク（LSDE）の起動サポート。
- Unity, Godot, RPG Maker, Unreal Engine, GameMaker, Construct3, Cocos2d, Phaser, Babylon.js, SugarCube, NovelStudio... のプリセット。
- カスタマイズ可能なi18nコンテキストマネージャー：複数形、性別、ブーリアンなど。

## 開発者 {#dev}
- キーの自動参照のためのコードベース解析システム。
- i18nキーが必要と思われる未加工テキストを特定するRAWスキャナー。
- 独自ゲームエンジン向けの構成済みおよびカスタマイズ可能なRegEx。
- 動的キーのサポート（例: `game:.scenes.${index}.events.1`）。
- コンテキストとデフォルトテキストの検出によるキーの自動作成。
- 検出されたが未作成のキーを表示するフィルター。
- ダブルクリックでソースコード内のキーの正確な位置をIDEで開く。
- 表示されるソースコードの行数制御。
- ソースコードの表示テーマ。
- i18nファイルの外部での同期ずれをリアルタイムで検出および可視化。
- ワンクリックの手動同期オプション。

## ツリー {#tree}
- 多彩なレンダリングモード：ツリー構造、フラットリスト（フルパス有無）、翻訳漏れ、参照のないキー、音声付き、進行中のタスク。
- キーまたは関連コンテンツによる検索。
- 素早い識別のために最適化された名前空間（ルート）フォルダのデザイン。
- 選択中のサブフォルダ数の表示。
- 選択内容に応じた自動インクリメントによるi18nキーのインテリジェント作成。
- 右クリックによる完全なコンテキストメニュー。
- `Ctrl+クリック`による複数選択。
- ドラッグ＆ドロップ（Drag & Drop）のサポート。
- 各アイテムのコンテキストタグ：複数形、性別、音声、未完了、コード内で不明など。
- コンテキストメニューを介した、サブフォルダを反復処理する一括（バッチ）タスク。

## LLM {#LLM}
- お気に入りモデルの管理。
- APIキーの安全な管理。
- エラー発生時の自動ローテーション（auto-roll）機能を備えた、複数のAPIキー登録。
- ネイティブタスクの管理とカスタマイズ：LLMに送信される指示とルール。

## 編集 / コンポジション {#editing}
- テーマとタイポグラフィのカスタマイズ：フォント、間隔、行の高さ、色、RTLサポート。
- 100%カスタマイズ可能なテキストレンダリングエンジン：変数、色、リンク、ツールチップ。
- 表示する言語とコンテキストのフィルタリング。
- RegEx対応の検索、置換、テキストナビゲーション。
- 各ダイアログを処理するタスクメニュー：翻訳、校正、リフレーズ、長さの調整、続きの生成。
- リアルタイムで構成可能なLLMスペルチェッカー。
- クイックアクションバー：ナビゲーション、レンダリング管理、コンテキストまたはキーの作成。
- 二重改行による段落モードオプション。
- クイック行削除（IDEの挙動）。
- テキスト選択時のコンテキストメニュー。
- 選択したテキストを囲むカスタマイズ可能なラッパーの管理。
- 操作回数に応じたインクリメンタルでリバーシブルなラッパー。
- バリデーションシステム：変更の検出、再確認が必要な翻訳、または無視する翻訳。
- タスク中の変更の比較と結果の微調整。
- タスクタイプごとのクイック設定の保存。
- SAD/MAD（1つのダイアログに1人または複数のアクター）パラダイムのサポート。
- 各文字列のキャラクターごとのボイス（オーディオ）管理。
- メタデータの可視化：画像、メモ、LLMコンテキスト、キャラクター、ボイス、アイコン。
- 依存変数とテキスト参照の表示。
