# Runtime (LSDEDE)

マルチランタイム実行エンジンは、エディターからエクスポートされたブループリントを読み込み、実行します。
TypeScript、C#、C++、GDScript で利用可能で、あらゆるゲームエンジンやフレームワークにネイティブに統合されます。
アーキテクチャはコールバック駆動型で、外部依存がなく、フレームワークに依存しません。
