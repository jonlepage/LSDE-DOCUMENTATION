# 翻訳

## 翻訳方法 {#how-to-translate}
::: tip メモ
LSDEは、世界のあらゆる言語への翻訳を可能にする強力なツールを提供しています。
:::
LLM（Large Language Models：大規模言語モデル）は、適切なコンテキスト（文脈）が提供されれば、翻訳において優れた性能を発揮する、人間によって設計された数学的アーキテクチャです。
は、デフォルトでLLMに送信される各リクエストにコンテキストを提供するため、より適切な結果が保証されます。

::: tip メモ
結果は満足のいくものであり、制作コストを大幅に削減できる可能性がありますが、最終的な確認のためにプロのスタジオに依頼することは依然として不可欠です。
:::

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-1.webp" />

LSDEでダイアログを翻訳するには、まず言語マネージャーからプロジェクトにサポートされている言語を追加しましょう。

1. [i18nローカライゼーション設定](/ja/interface/localization-manager#patterns)ウィンドウを開きます。
2. 指定されたボタンからプロジェクトに言語を追加します。
3. 必要な言語とプロジェクトの主要言語を選択します。
選択肢は「`ISO 639-1`」および「`ISO 3166-1`」形式です。

言語を追加したら、プロジェクトの主要言語を正しく設定してください。このステップは、ソフトウェアのほとんどのアクションをアンロックするために不可欠です。

::: tip メモ
主要言語は理想的には確定されているべきですが、いつでも変更可能です。
:::

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-2.webp" left />

1. 次に、ツリー構造からキーを選択します。この選択により、エディターのメインウィンドウに関連するすべてのダイアログが表示されます。
2. その後、作業したい言語をフィルタリングできます。

::: tip メモ
右クリックで、すべての言語の表示と主要言語のみの表示を素早く切り替えることができます。
:::

---

## LLMによる翻訳 {#translate-with-llm}
<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-3.webp" />

1. まずエディター内のダイアログをクリックして、編集を有効にします。
アイコンが表示され、メニューから目的のタスクを管理できます。

デフォルトで、は事前設定されたタスクを提案します。
この特定のケースでは、「翻訳（Traduire）」タスクを使用します。

::: tip メモ
利用可能なタスクは、必要に応じてグローバル設定で再設定できます。
:::
2. 翻訳タスクを選択しましょう。

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-4.webp" />

タスクの詳細を調整するための設定ウィンドウが開きます：
1. 実行前に特定のフィルターを有効または無効にする機能。
2. 反復（イテレーション）深度の調整（処理がフォルダーを対象とする場合）。
3. 現在の設定に基づいた、無視されたキーの表示/非表示。
4. 自動設定で不十分な場合、含めるインスタンスを手動で有効化/無効化。
5. LLMをガイドするための追加の指示（ディレクティブ）の追加。

::: tip メモ
キーボードの上下矢印を使用して、グローバル履歴をナビゲートします。
:::

設定が完了したら、右下の「確認（Confirmer）」をクリックします。

::: tip メモ
タスクが作成されると、自動処理システムに送信されます。このシステムは、プロジェクトを開くと同時にアクティブになり、進行中のタスクを再開します。
:::

---

タスクに割り当てられたすべてのインスタンスが比較モードに切り替わり、左側に元のテキスト、右側に回答を表示できるようになります。

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-5.webp" left />

1. このボタンは、元のテキストに対して追加された文字数を表示します。

::: tip メモ
追加されたトークンの表示/非表示も可能です。
:::
2. このボタンは、削除された文字数を表示します。

::: tip メモ
削除されたトークンの表示/非表示も可能です。
:::
3. このボタンは、最終的な全体の状態（文字数の増減）を表示します。

::: tip メモ
該当するテキスト部分をクリックして変更をキャンセルした場合、最終的なレンダリングに切り替えることもできます。
:::
4. 変更のレンダリング：各タグをクリックして、不要な変更を元に戻すことができます。
5. LLMに追加の指示を送信することで、必要な回数だけ反復（イテレート）できます。

::: tip メモ
使用するモデルによってはキャッシュが体系的に行われないため、反復ごとに全履歴が再送信され、コストが指数関数的に増加する可能性があります。
:::
6. テレメトリ：LLMプロバイダーから返されたトークンコストを表示します。
7. 調整が終わった後に変更を承認または拒否するためのボタン。
8. 「Experimental（実験的）」：特定のシナリオ（例：一連の対話でLLMが元のテキストを返さない場合など）に応じて自動修正を追加できます。
9. 以前のバージョンに戻るための変更履歴のナビゲート。

---

結果に満足したら、それを確定し、必要に応じて手動で最終的な詳細を調整してください。
