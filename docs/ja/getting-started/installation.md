# インストール

Pourダウンロードするには、[LS-Installer](https://lepasoft.com/ja/software/ls-dialog-editor#download)の、お使いのオペレーティングシステムと互換性のあるバージョンを選択してください。圧縮版（[ZIP](https://wikipedia.org/wiki/ZIP_(file_format))形式）を選択した場合は、選択したフォルダーにコンテンツを抽出してください。

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## LS-INSTALLERとは？ {#what-is-lsinstaller}
LS-Installerは、**Lepasoft**のゲームやソフトウェアのインストールを容易にするために設計された**インタラクティブなランチャー**です。
LS Dialog Editorをインストールするには、利用可能な製品リストから選択し、以下の手順に従ってください。
1. 利用規約を読み、同意します。
2. インストールディレクトリを選択します。
3. ダウンロードを開始します。
4. 希望するインストール後オプションをチェックします。
5. デスクトップのショートカットまたはインストールフォルダーから直接アプリケーションを起動します。

::: tip メモ
インストーラーは、選択された製品の最新バージョンを自動的にダウンロードします。
:::

## LS-Installerの問題？ {#issue-with-lsinstaller}
ランチャーが起動しない場合、ソフトウェアの署名があるにもかかわらず、オペレーティングシステムがその実行をブロックしている可能性があります。
この場合、代わりに圧縮版をダウンロードし、自動ではなく手動で抽出を行ってください。
現在ベータ版であり、**ソフトウェアにはローカル署名が含まれています**が、Microsoft Storeによって検証された署名はまだありません。

::: tip メモ
インストールアプリケーションはオープンソースであり、難読化されていません。任意の逆コンパイルソフトウェアで逆アセンブルして、そのソースコードを表示できます。
Microsoft WindowsやApple macOSのようなオペレーティングシステムでは、有料の認証サービスを通じて署名が検証されていない場合、ソフトウェアのブロックは一般的です。良い評判を得たソフトウェアは、数年間存在した後、繰り返しの認証費用なしでも、このブロックを回避できる場合があります。
:::
