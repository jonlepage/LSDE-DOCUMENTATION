# メタデータ

メタデータウィンドウでは、キーとその子孫に配布可能な追加情報をキーに追加できます。

## なぜメタデータを使用するのか？ {#why-use-metas}
タスクの実行時、これらの情報はLLMへのリクエストに組み込まれます。
入力された情報は、メタデータビジュアライザーでいつでも参照できます。
ビューは、アクティブなキーからプロジェクトのネームスペースのルートまで、上から下へ再帰的に表示されます。

::: tip メモ
ソースプロジェクトはメタデータに依存すべきではありません。これらは純粋に情報提供を目的としており、執筆と考察にのみ影響を与えるべきです。
:::

**これらの情報には、いくつかの利点があります：**
- 翻訳者/ライターがコンテキストを理解するのに役立ちます。
- キーの親から再帰的に情報を視覚化できます。
- キーまたは隣接するキーの処理のために、LLMに関連情報を追加できます。

::: tip メモ
同じフォルダー内のキーの場合、LLMは隣接するキーも読み取り、物語の流れを理解します。
:::
- キーツリー内のアイコンと色をカスタマイズして、識別性を向上させることができます。
- 画像を追加して、ダイアログを視覚的にコンテキスト化できます。
- LLMが使用できる変数を有効/無効にできます。

## メタデータインターフェース {#metas-interface}
<DocImage src="/doc/lsde/doc-lsde-ui-metadata.webp" />

0. **再帰深度**
アクティブなキーからその階層的な親までの、取得される情報の範囲を制限します。
1. **説明（LLM）**
キーがLLMに送信される際に考慮される情報です。キーの所属、その周囲、および子キーの役割をコンテキスト化します。
2. **許可された変数**
LLMがタスクを最適化するために処理する変数を追加できます。たとえば、キャラクター変数を許可し、LLMにクエストフォルダーにこれらのキャラクターのみを含めるよう要求します。追加のキャラクターは、LLMによって再割り当て/削除されたり、追加のインタラクションを作成するために使用されたりすることがあります。
3. **音声変数**
音声変数グループが設定されている場合、ここに話者を割り当てます。

::: tip メモ
LLMは、ダイアログをチェックするために、これらを優先的に使用することもできます。
:::
4. **ユーザーノート**
作成者、翻訳者、またはご自身用のメモやリマインダーをここに記述します。

::: tip メモ
LLMはこれらにアクセスできません。ノートは.lsdeファイルに組み込まれるため、Git経由で共有またはバージョン管理される場合は、機密情報を避けてください。
:::
5. **画像**
フォルダーまたはキーをコンテキスト化するために画像を表示します。ソースコードやプレビューにアクセスできない翻訳者にとって非常に役立ちます。

::: tip メモ
画像は、共有を容易にするために.lsdeファイル内で圧縮および劣化されます。
:::
6. **親要素**
これらのセクションは、親の情報を上から下へ再帰的に表示します。
7. **編集**
このボタンはメタデータの編集モードを有効にします。

::: tip メモ
デフォルトでは、メタデータは読み取り専用です。
:::
8. **編集アクション**
編集モードでは、変更をキャンセルまたは適用します。編集モード中にキーを変更すると、前のキーが自動的に保存されます。
9. **変数フィルター**
このボックスは、有効にする変数グループをフィルターし、**変数の適切な初期編成の重要性**を強調します。
