# ようこそ画面

LSDEのスタート画面は、エクスプローラーからプロジェクトファイルを開かずにアプリケーションを直接起動するたびに表示されます。
これは3つの主要なセクションに分かれています。

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## インターフェース言語の選択 {#interface-language-choice}
このセクションでは、ソフトウェアのインターフェース表示言語を選択できます。
`[F1]` キーを使用すると、最後に選択した2つの言語を素早く切り替えることができます。

::: tip メモ
教育目的のこのソフトウェアは、母国語から好きな第二言語へと非常に素早く切り替えることができます。
:::

## 起動時のアクション {#startup-actions}
これらのオプションでプロジェクトを開始できます。
- **プロジェクトの読み込み**：既存のプロジェクトを開いて読み込みます。
- **新規プロジェクト**：プリセットあり、またはプリセットなしで新しいプロジェクトを作成します。
- **デモ**：インスピレーションを得たり、さまざまなワークフローを探索したりするためにデモンストレーションプロジェクトを読み込みます。

## 最近のプロジェクト {#recent-projects}
このセクションには最近開いたプロジェクトが表示され、頻繁に使用するプロジェクトに素早くアクセスして作業を再開できます。

---
