# Голос

<DocImage src="/doc/lsde/doc-lsde-features-howto-generatevoice-1.webp" />

LSDE включает функцию для управления саундтреком вашего проекта, синхронизированным с вашими диалогами.

## Предварительные требования {#prerequisites}
Сначала вам нужно будет получить ключ API [Elevenlabs](/ru/interface/global-settings#llm-pour-les-voix).
Elevenlabs в настоящее время предлагает бесплатный месячный план, который идеально подходит для тестирования их API и ознакомления с их опытом.

## Конфигурация {#configuration}
Чтобы настроить голосовую систему вашего проекта, перейдите в [раздел настройки голосов](/ru/interface/project-settings#voices).

1.  Определите папку для экспорта голосов, которые будут сохраняться при каждом сохранении проекта.
2.  Система позволяет именовать выходные файлы.
    Эта опция адаптирует имена к потребностям вашего игрового движка или проекта.
    Перетаскивание настраивает порядок меток.

## Связать переменные (автоматически) {#associate-variables-auto}
<DocImage src="/doc/lsde/doc-lsde-features-howto-generatevoice-2.webp" />

Этот пример показывает, как настроить голосовую систему для JRPG с несколькими персонажами в диалоге, где ваш игровой движок должен их извлекать.

1.  Выберите группу переменных для ваших собеседников.
2.  Установите флажок *Несколько собеседников в диалоге*.
3.  Откроется раздел для настройки регулярного выражения (`regex`) с обязательной 1 группой:
    -   Группа `id`: Захватывает значение `tag` для поиска в переменных выбранной группы.
    -   Группа `value`: Захваченный текст для группы `id`.
    > Необязательно, так как вы можете написать текст. Эта группа максимально автоматизирует процесс и снижает рабочую нагрузку.

4.  Вы увидите все переменные настроенной группы с их соответствующими значками, если они указаны.

Вы можете протестировать свой `regex`, чтобы лучше понять его на [regexr](https://regexr.com).
regex: `xxxxxxxxx`
```text
xxxxxxxxxxxxxxxx
xxxxxxxxxxxxxx
xxxxxxxxxxxxx
```
1.  Выбрав, например, второй захват.
2.  Перейдите к 'Подробностям'.
3.  Вы увидите, что:
    -   Группа 1 захватывает `tag id` вашего персонажа *a1*.
    -   Группа 2 захватывает остальной текст для `id` *a1*.

## Переменные {#variables}
В [разделе переменных](/ru/interface/project-settings#les-variables):

1.  В группе `ACTORS`, созданной ранее.
2.  Этот список будет соответствовать тому, который [был показан ранее](/ru/features/voice#associer-des-variables).
3.  Указание внешнего вида значительно упрощает организацию и проверку диалогов и личностей персонажей.

::: tip Примечание
Обратите внимание, что вы можете изменить эту информацию в любое время или дополнить ее позже.
:::

## Настроить персонажа {#configure-character}
Вернемся к [настройке голосов](/ru/features/voice#associer-des-variables).

1.  Привяжите ID голоса к вашей переменной.
    > ID голосов создаются на платформе Elevenlabs. Ваш аккаунт Elevenlabs уже включает стандартные модели.
2.  Вы также сможете тестировать и настраивать генератор голоса.

---

<DocImage src="/doc/lsde/doc-lsde-features-howto-generatevoice-6.webp" />

## Создать ID голоса {#create-voice-id}
В вашем профиле [elevenlabs](https://elevenlabs.io/app/voice-lab):

1.  Создайте новый пользовательский голос.
    LSDE поддерживает все модели API. Настоятельно рекомендую в настоящее время модель `V3` за ее управление эмоциональными `tags`, предлагающее лучший нарративный контроль.
2.  После создания перейдите в раздел ваших голосов.
3.  Проверьте наличие ID (например: *Lia Sun-berry*, главный персонаж [FCT7O](https://lepasoft.com/ru/games/fanatic-cardboard-f7o)).

---

<DocImage src="/doc/lsde/doc-lsde-features-howto-generatevoice-7.webp" />

## Сгенерировать голосовой текст {#generate-voice-text}
После указания ID, чтобы просмотреть или сгенерировать голосовые тексты, откройте окно [менеджера голосов](/ru/interface/voice-manager).

1.  Выберите ключ в древовидной структуре.
    Не выбирайте папку, так как голосовые тексты отображаются там только для чтения.
2.  `regex` захватит персонажей диалога и предложит интерфейс генерации голоса.
3.  Во время генерации текст получает *подпись* в текущий момент. Если текст меняется без изменения порядка персонажей, появится предупреждение, предлагающее проверить необходимость повторной генерации голоса.

## Настроить метаданные {#configure-metas}
Привяжите к каждому диалогу персонажа или персонажей, для которых вы хотите сгенерировать голоса.

1.  Выберите ключ целевого диалога.
2.  Отметьте каждого актера, которого нужно обрабатывать для этого диалога.

### Почему несколько персонажей? {#why-multiple-characters}
Это может быть полезно для общих диалогов, таких как приветственная фраза, повторно используемая несколькими случайными PNJ с разными личностями или полами.

## Реорганизация {#reorganization}
1.  Всегда по ключу, а не по папке.
2.  Менеджер голосов может сообщить о проблеме реорганизации.
    В этом примере мы перешли от автоматического назначения нескольких персонажей к ручной системе.

::: tip Примечание
Если система обнаруживает серьезные изменения в порядке или количестве персонажей, вам придется вручную реорганизовать каждый уже сгенерированный голосовой экземпляр.
:::

<DocImage src="/doc/lsde/doc-lsde-features-howto-generatevoice-11.webp" />

Вам просто нужно перетащить каждый файл голосового диалога к соответствующему персонажу, объявленному в метаданных или через систему автоматического назначения.
