# Перевод

## Как переводить {#how-to-translate}
::: tip Примечание
LSDE предлагает мощные инструменты, позволяющие нам переводить на все языки мира.
:::
LLM (*Large Language Models*) — это созданные человеком математические архитектуры, которые отлично справляются с переводом при условии предоставления им соответствующего контекста.
LS Редактор диалогов по умолчанию предоставляет контекст для каждого запроса к LLM, что гарантирует более релевантные результаты.

::: tip Примечание
Хотя результаты являются удовлетворительными и могут значительно снизить производственные затраты, для финальной проверки все же необходимо привлекать профессиональную студию.
:::

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-1.webp" />

Чтобы перевести диалог в LSDE, начнем с добавления поддерживаемых языков в наш проект через менеджер языков.

1. Откройте окно [конфигурации локализаций i18n](/ru/interface/localization-manager#patterns).
2. Добавьте языки в ваш проект с помощью указанной кнопки.
3. Выберите нужные языки, а также основной язык проекта.
Предложенные варианты соответствуют форматам `ISO 639-1` и `ISO 3166-1`.

После добавления языков обязательно правильно определите основной язык проекта. Этот шаг необходим для разблокировки большинства действий в программе.

::: tip Примечание
Хотя основной язык в идеале должен быть окончательным, его можно изменить в любой момент.
:::

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-2.webp" left />

1. Затем выберите ключ в дереве. При этом в главном окне редактора отобразятся все связанные с ним диалоги.
2. После этого вы можете отфильтровать языки, с которыми хотите работать.

::: tip Примечание
Щелчок правой кнопкой мыши позволяет быстро переключаться между отображением всех языков или только основного языка.
:::

---

## Перевод с помощью LLM {#translate-with-llm}
<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-3.webp" />

1. Сначала нажмите на диалог в редакторе, чтобы активировать его редактирование.
Появится иконка, позволяющая управлять нужной задачей через меню.

По умолчанию LS Редактор диалогов предлагает уже настроенные задачи.
В данном конкретном случае мы будем использовать задачу *Traduire* (Перевести).

::: tip Примечание
Доступные задачи могут быть перенастроены в глобальных параметрах при необходимости.
:::
2. Выберем задачу перевода.

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-4.webp" />

Откроется окно конфигурации для настройки деталей задачи:
1. Возможность включения или выключения определенных фильтров перед запуском.
2. Настройка глубины итерации (если обработка касается папки).
3. Отображение/скрытие игнорируемых ключей согласно текущим настройкам.
4. Ручная активация/деактивация экземпляров для включения, если автоматических настроек недостаточно.
5. Добавление дополнительных директив для руководства LLM.

::: tip Примечание
Используйте стрелки вверх/вниз на клавиатуре для навигации по вашей глобальной истории.
:::

После выполнения настроек нажмите *Confirmer* (Подтвердить) в нижнем правом углу.

::: tip Примечание
Как только задача создана, она передается в систему автоматической обработки. Последняя активируется сразу при открытии проекта, чтобы возобновить выполнение текущих задач.
:::

---

Все экземпляры, назначенные на задачу, переходят в режим сравнения, позволяя визуализировать исходный текст слева и ответ справа.

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-5.webp" left />

1. Эта кнопка показывает количество букв, добавленных по сравнению с оригинальным текстом.

::: tip Примечание
Она также позволяет отображать или скрывать добавленные токены.
:::
2. Эта кнопка показывает количество удаленных букв.

::: tip Примечание
Она также позволяет отображать или скрывать удаленные токены.
:::
3. Эта кнопка отображает конечное глобальное состояние (положительный или отрицательный баланс символов).

::: tip Примечание
Она также позволяет переключиться на финальный рендеринг, если вы отмените изменения, нажав на соответствующие фрагменты текста.
:::
4. Рендеринг изменений: вы можете нажать на каждый тег, чтобы отменить нежелательное изменение.
5. Вы можете итерировать столько раз, сколько необходимо, отправляя дополнительные директивы LLM.

::: tip Примечание
в зависимости от используемой модели кэширование не всегда является систематическим, что может экспоненциально увеличить затраты, так как при каждой итерации отправляется вся история целиком.
:::
6. Телеметрия: отображает затраты в токенах, возвращаемые провайдером LLM.
7. Кнопки для принятия или отклонения изменений после завершения уточнения.
8. *Experimental*: позволяет добавлять автоматические исправления согласно определенным сценариям (например, если LLM не возвращает исходный текст в ходе цепочки обсуждения).
9. Навигация по истории изменений для возврата к предыдущей версии.
