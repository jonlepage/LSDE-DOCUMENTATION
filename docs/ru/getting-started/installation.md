# Установка

Чтобы скачать [LS-Installer](https://lepasoft.com/ru/software/ls-dialog-editor#download), выберите версию, совместимую с вашей операционной системой. Если вы выберете сжатую версию в формате [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)), распакуйте содержимое в выбранную вами папку.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## Что такое LS-INSTALLER? {#what-is-lsinstaller}
LS-Installer — это **интерактивный установщик**, разработанный для упрощения установки игр и программного обеспечения **Lepasoft**.
Чтобы установить LS Dialog Editor, достаточно выбрать его из списка доступных продуктов, а затем выполнить следующие шаги:
1. Прочтите и примите условия использования.
2. Выберите каталог установки.
3. Запустите загрузку.
4. Отметьте желаемые параметры после установки.
5. Запустите приложение с помощью ярлыка на рабочем столе или непосредственно из папки установки.

::: tip Примечание
Установщик автоматически загружает самую последнюю версию выбранного продукта.
:::

## Проблемы с LS-Installer? {#issue-with-lsinstaller}
Если установщик не запускается, возможно, ваша операционная система блокирует его выполнение, несмотря на цифровую подпись программного обеспечения.
В этом случае лучше скачайте сжатую версию и выполните извлечение вручную, а не автоматически.
В настоящее время программное обеспечение находится в бета-фазе, **включает локальную подпись**, но пока не имеет подписи, подтвержденной Microsoft Store.

::: tip Примечание
Установочное приложение с открытым исходным кодом и не обфусцировано. Его можно деассемблировать с помощью любого программного обеспечения для декомпиляции для просмотра его исходного кода.
Блокировка программного обеспечения распространена в операционных системах, таких как Microsoft Windows и Apple macOS, когда подписи не были подтверждены через их платные службы сертификации. Программное обеспечение, завоевавшее хорошую репутацию, иногда может избежать этой блокировки после нескольких лет существования, даже без регулярных платежей за сертификацию.
:::
