# Первый шаг

## Запуск {#getting-started}
При первом запуске программы **вам будет предложено начать пробный период** или ввести лицензионный ключ.
- **Пробный период:**
Пробный период позволяет вам протестировать программу со всеми ее функциями в течение определенного времени.

::: tip Примечание
Во время бета-фазы пробный период неограничен и будет сброшен после ее окончания.
:::

- **Лицензия:**
Если у вас есть лицензия, введите ее, чтобы разблокировать программу.

::: tip Примечание
Ваш ключ был отправлен вам по электронной почте после завершения транзакции.
Вы не можете приобрести ключ в течение бета-периода программы.
:::

## Выбор языка интерфейса {#interface-language-choice}
LSDE предлагает 3 основные опции при запуске:

## Загрузить проект {#load-project}
<DocImage src="/doc/lsde/lsde-banner.webp" h="30" left icon />

Вы можете выбрать файл с расширением `.lsde`.

::: tip Примечание
Если установлены ассоциации файлов, двойной щелчок по файлу .lsde в вашем проводнике позволяет открыть проект напрямую.
:::

## Новый проект {#new-project}
Эта опция позволяет создать новый проект, предварительно настроив параметры для определенных типов проектов.
Вы также можете предварительно установить наиболее популярные языки в Steam.
Обратите внимание, что эти предварительные настройки не являются окончательными; их можно изменить в любое время в рамках проекта.

::: tip Примечание
Сохраняйте свои проекты в папке, поддерживаемой Git или другой системой. Файлы .lsde не содержат конфиденциальных данных.
:::
В нижней части экрана вы также найдете список недавно открытых проектов, что позволит вам быстро возобновить рабочую сессию.

## Демонстрационные проекты {#demo-project}
Несколько демонстрационных проектов включены в программу. Они позволяют вам наблюдать некоторые функции в действии или вдохновиться для вашего рабочего процесса.

# Обязательная настройка {#mandatory-configuration}
Чтобы в полной мере использовать LSDE и начать работу, вам обязательно потребуется выполнить первый шаг начальной настройки.
Этот быстрый и важный шаг необходим для разблокировки всех функций программы, специфичных для вашего проекта.

Значок окна управления локализациями, расположенный в правом верхнем углу в меню быстрых окон, будет мигать, чтобы сообщить вам, что требуется важная информация.

Находясь в окне управления локализациями, вам потребуется либо:
- Импортировать существующую папку вашего проекта, которая уже содержит языковые файлы и директории.
- Либо вручную добавить языки и пространство имен (`namespace`).

Затем выберите основной язык проекта, и вы будете готовы использовать LSDE.
Для получения дополнительной информации о менеджере локализаций [обратитесь к этому разделу](/ru/interface/localization-manager)
