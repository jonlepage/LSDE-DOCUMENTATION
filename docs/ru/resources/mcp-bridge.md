# MCP Bridge

MCP Bridge сервер позволяет внешним инструментам и агентам AI взаимодействовать с редактором через стандартный протокол MCP (Model Context Protocol).

## Что такое MCP? {#what-is-mcp}
MCP — это открытый протокол, который позволяет языковым моделям и агентам AI обмениваться данными с внешними приложениями.
Ваша IDE (VS Code, Cursor и т.д.) может автоматически подключаться к серверу MCP для расширения возможностей вашего AI-ассистента.
Подключение осуществляется через файл конфигурации `.mcp.json`, расположенный в корне вашего проекта — ручная установка не требуется.

## Конфигурация {#configuration}
Создайте или отредактируйте файл `.mcp.json` в корне вашего проекта, чтобы добавить в него сервер:
```json
{
	"mcpServers": {
		"lsde": {
			"command": "npx",
			"args": ["-y", "@lsde/mcp-server@latest"],
			"env": {
				"LSDE_MCP_PORT": "9225"
			}
		}
	}
}
```
После того как этот файл будет создан, перезапустите вашу IDE (или расширение AI), чтобы сервер был обнаружен.
Процесс полностью автоматизирован: пакет загружается через `npx`, и сервер запускается в фоновом режиме.

[Пакет npm: @lsde/mcp-server](https://www.npmjs.com/package/@lsde/mcp-server)

## Возможности {#capabilities}
MCP Bridge сервер позволяет внешним агентам:
- **Читать структуру проекта** — Дерево сцен, блоков, соединений и метаданных.
- **Просматривать узлы** — Доступ к тексту и свойствам любого узла графа.
- **Управлять переменными** — Чтение и взаимодействие с переменными и словарями проекта.
- **Запускать генерацию сцен** — Создавать новые сцены с помощью структурированных команд.
- **Предлагать изменения** — Отправлять изменения текста или структуры на проверку.

## Варианты использования {#use-cases}
- **Claude Code / Cursor** — Интегрируйте редактор в свой рабочий процесс разработки с помощью AI.
- **Автоматизированные конвейеры** — Подключайте редактор к своим скриптам сборки или CI/CD.
- **QA-агенты** — Автоматически проверяйте повествовательную согласованность ваших диалогов.
- **Пользовательские инструменты** — Создавайте собственные интеграции через стандартный протокол.

## Доступность {#availability}
MCP Bridge доступен в планах **Профессиональный** и **Корпоративный/Образовательный**.
