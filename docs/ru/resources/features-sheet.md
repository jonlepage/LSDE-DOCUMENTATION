# Список функций

Публичная бета-версия вносит значительные улучшения в пользовательский опыт (UX) и функциональность для поддержки проектов любого типа. 
Вот краткий обзор возможностей (Cheat Sheet):

## Общее {#general}
- Компактный, современный и эргономичный интерфейс.
- Интерфейс полностью переведен на 10 языков: fr, en, es, de, it, pl, ja, ko, zh, ru.
- Быстрое переключение интерфейса между двумя основными языками с помощью `[F1]`.
- Модульная система макетов с закрепляемыми окнами (идеально для многоэкранных конфигураций).
- Полноэкранный режим для всех окон.
- Всплывающие подсказки для всех кнопок при наведении.
- Доступность: специальные опции для дальтонизма и нарушений зрения.
- Горячие клавиши для быстрых действий в зависимости от контекста.
- Несколько Zen-режимов для концентрации во время написания текста.
- Статистика проекта в реальном времени: ключи, слова, символы, токены, нажатия клавиш, выделения.
- Быстрое создание проекта с пошаговым руководством и преднастройкой в один клик.
- Файлы проектов `.lsde` в формате JSON, совместимые с версионным контролем (Git) и удобные для совместного использования.
- Системная поддержка (OS) иконок и открытия проектов с расширением `.lsde`.
- Опция автоматического повторного открытия последнего проекта.
- История последних открытых проектов.
- Обнаружение неожиданных завершений работы с восстановлением сессии.
- Индивидуальный импорт/экспорт глобального профиля конфигурации LSDE.
- Включение/выключение и смена модели LLM в один клик.
- Поддержка встроенного резервного (fallback) LLM — бесплатно и анонимно, без учетной записи или API-ключа.
- Поддержка LLM-копилотов: Claude, DeepSeek, Gemini, GPT, Mistral, Ollama, ElevenLabs...
- Поддержка локальных LLM через `localhost`.
- Встроенный LLM-ассистент, обученный на документации, для помощи пользователю.
- Меню LLM-помощи для полей конфигурации: помощь, заполнение, улучшение, перевод.
- Диагностика и управление внутренними ошибками и предупреждениями.
- Полная документация по LSDE и i18n доступна онлайн.
- Поддержка открытия ссылок как внешних (браузер), так и внутренних (LSDE).
- Предварительные настройки для: Unity, Godot, RPG Maker, Unreal Engine, GameMaker, Construct3, Cocos2d, Phaser, Babylon.js, SugarCube, NovelStudio...
- Управление настраиваемыми контекстами i18n: множественное число, род, булевы значения и т. д.

## Разработчик {#dev}
- Система анализа кодовой базы для автоматической привязки ключей.
- RAW-сканер для поиска необработанного текста, которому могут потребоваться ключи i18n.
- Преднастроенные и настраиваемые RegEx для проприетарных игровых движков.
- Поддержка динамических ключей (например: `game:.scenes.${index}.events.1`).
- Автоматическое создание ключей с определением контекста и текста по умолчанию.
- Фильтр отображения обнаруженных, но еще не созданных ключей.
- Двойной клик для открытия IDE точно на месте расположения ключа в исходном коде.
- Контроль количества отображаемых строк исходного кода.
- Темы отображения исходного кода.
- Обнаружение и визуализация внешней рассинхронизации файлов i18n в реальном времени.
- Опция ручной синхронизации в один клик.

## Дерево {#tree}
- Несколько режимов отображения: дерево, плоский список (с полным путем или без), пропущенные переводы, ключи без ссылок, с аудио или с текущей задачей.
- Поиск по ключу или по связанному контенту.
- Дизайн папок неймспейсов (root), оптимизированный для быстрой идентификации.
- Отображение количества подпапок при выборе.
- Интеллектуальное создание ключей i18n с автоинкрементом на основе выбора.
- Полное контекстное меню по правому клику.
- Множественный выбор через `Ctrl+клик`.
- Поддержка Drag & Drop.
- Контекстные теги для каждого элемента: множественное число, род, голос, незавершенность, неизвестность в коде и т. д.
- Пакетные задачи (batch) через контекстное меню для итерации по подпапкам.

## LLM {#LLM}
- Управление избранными моделями.
- Безопасное управление API-ключами.
- Возможность сохранения нескольких API-ключей с автоматической ротацией (auto-roll) в случае ошибок.
- Управление и настройка встроенных задач: инструкции и правила, отправляемые в LLM.

## Редактирование / Композиция {#editing}
- Настройка темы и типографики: шрифты, межстрочные интервалы, цвета и поддержка RTL.
- Полностью настраиваемый движок рендеринга текста: переменные, цвета, ссылки, подсказки.
- Фильтрация отображаемых языков и контекстов.
- Поиск, замена и текстовая навигация с поддержкой RegEx.
- Меню задач для обработки каждого диалога: перевод, исправление, перефразирование, регулировка длины, продолжение текста.
- Настраиваемая проверка орфографии с помощью LLM в реальном времени.
- Панель быстрых действий: навигация, управление рендерингом, создание контекстов или ключей.
- Опция режима параграфа через двойной разрыв строки.
- Быстрое удаление строки (поведение как в IDE).
- Контекстное меню при выделении текста.
- Менеджер настраиваемых оберток (wrappers) для выделенного текста.
- Инкрементальные и обратимые обертки в зависимости от количества взаимодействий.
- Система валидации: обнаружение изменений, переводы для повторной проверки или игнорирования.
- Сравнение изменений и уточнение результатов во время выполнения задачи.
- Сохранение быстрых конфигураций для каждого типа задач.
- Поддержка парадигм SAD/MAD (Single/Multi Actor Per Dialog).
- Управление голосами (аудио) для каждого персонажа и каждой строки.
- Визуализация метаданных: изображения, заметки, LLM-контексты, персонажи, голоса, иконки.
- Отображение зависимых переменных и текстовых ссылок.
