# Редактор диалогов

Эта секция представляет собой отображаемое содержимое ключей. Редактор организует выбранный ключ вертикально и рекурсивно, отображая его содержимое на всех языках, его контексты и дочерние ключи.
Он предлагает опции навигации и рендеринга для фильтрации языков и контекстов, а также инструменты для действий и телеметрии.

## Система рендеринга {#rendering-system}
LSDE имеет систему рендеринга "пост-обработки" для настройки отображения текста, что облегчает чтение и редактирование.
Настройте шаблоны Regex для захвата групп текста и назначения им декораций.
Эти захваты могут быть связаны с переменными для предоставления дополнительной информации переводчику, редактору или LLM.
[Перейдите в расширенный раздел о рендеринге и создании шаблонов](/ru/features/rendering)

## Инструменты заголовка {#header-tools}
1. **Включить/Отключить пост-рендеринг**
Быстро отключает рендеринг шаблонов.
2. **Навигация**
Кнопки для быстрой навигации между следующим и предыдущим ключами.
3. **Создать ключ**
Быстро создает новый ключ.
4. **Показать/Скрыть контексты**
Показывает или скрывает контексты, связанные с ключом, для упрощения просмотра.
Каждая иконка соответствует метке настроенных контекстов.
5. **Показать/Скрыть языки**
Фильтрует языки для одновременной работы.

::: tip Примечание
Эти фильтры также используются LSDE для других системных операций, влияя таким образом на другие диагностические инструменты.
:::

## Зоны редактирования {#editing-zones}
Эта зона отображает текст активных языков и текущие задачи для ключа.
6. **Выбрать ключ в дереве**
Находит и выбирает ключ в дереве.

::: tip Примечание
Полезно для редактирования метаданных, возможно только для активного ключа.
:::
7. **Задачи**
Меню предлагает задачи, применимые к этому ключу, его связям и дочерним ключам.
8. **Защитить**
Установите этот флажок, чтобы пометить текст как окончательный и защищенный, игнорируя при этом определенные задачи и операции.
Отключение этой опции предлагает отключить все проверки других языков, связанных с этим ключом.
0. **Ключ**
Отображает полный путь ключа, **в формате LSDE**

## Поиск/Замена {#search-replace}
8. **Поиск/замена**
[CTRL+F] открывает внутренний инструмент поиска.
Он предлагает режим Regex для сложных случаев.
Поиск также может быть запущен через контекстное меню.

## Производительность {#performance}
По умолчанию LSDE отключает сложный рендеринг (виджеты) в неактивных окнах.
Это обеспечивает хороший компромисс между визуальным опытом и низкой задержкой.
Если производительность не является проблемой, отключите эту оптимизацию в глобальных конфигурациях.

::: tip Примечание
Может потреблять ресурсы, если несколько языков отображаются одновременно, поскольку система рендеринга сегментирована по ключу.
:::
