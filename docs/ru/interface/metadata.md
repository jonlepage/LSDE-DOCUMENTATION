# Метаданные

Окно метаданных позволяет добавлять дополнительную информацию к ключу, распространяющуюся на этот ключ и его дочерние элементы.

## Зачем использовать метаданные? {#why-use-metas}
При выполнении задач эта информация интегрируется в запросы LLM.
Введенная информация также доступна для просмотра в любое время в средстве просмотра метаданных.
Представление рекурсивное, сверху вниз, от активного ключа до корня пространства имен проекта.

::: tip Примечание
Ваш исходный проект не должен зависеть от метаданных. Они носят чисто информативный характер и должны влиять только на написание и обдумывание.
:::

**Эта информация может предоставить следующие преимущества:**
- Помочь переводчикам/редакторам понять контекст.
- Визуализировать информацию рекурсивно, начиная от родительских элементов ключа.
- Добавить релевантную информацию для LLM для обработки ключа или соседних ключей.

::: tip Примечание
Для ключа в той же папке LLM также читают соседние ключи для понимания повествовательного потока.
:::
- Настроить значок и цвет в дереве ключей для лучшей идентификации.
- Добавить изображения для визуальной контекстуализации диалога.
- Включать/выключать переменные, используемые LLM.

## Интерфейс метаданных {#metas-interface}
<DocImage src="/doc/lsde/doc-lsde-ui-metadata.webp" />

0. **Рекурсии**
Ограничивает диапазон извлекаемой информации, от активного ключа к его иерархическим родителям.
1. **Описания (LLM)**
Информация, учитываемая, когда ключ отправляется в LLM. Она контекстуализирует принадлежность ключа, его окружение и роль его дочерних элементов.
2. **Разрешенные переменные**
Позволяет добавлять переменные для обработки LLM для оптимизации их задач. Например, разрешите переменные персонажей и попросите LLM, чтобы только они фигурировали в папке квеста. Дополнительные персонажи могут быть переназначены/удалены LLM или использованы для создания дополнительных взаимодействий.
3. **Голосовые переменные**
Назначьте здесь собеседников, если группа голосовых переменных настроена.

::: tip Примечание
LLM также могут использовать их в приоритетном порядке для проверки диалогов.
:::
4. **Пользовательские заметки**
Здесь пишите заметки и напоминания для композиторов, переводчиков или для себя.

::: tip Примечание
LLM не имеют к ним доступа. Поскольку заметки интегрированы в файл .lsde, избегайте в них конфиденциальной информации, если файл общий или версионируется через Git.
:::
5. **Изображения**
Отображайте изображения для контекстуализации папки или ключа. Очень полезно для переводчика без доступа к исходному коду или предварительному просмотру.

::: tip Примечание
Изображения сжимаются и ухудшаются в файле .lsde для облегчения обмена.
:::
6. **Родительские элементы**
Эти разделы рекурсивно отображают информацию о родительских элементах, сверху вниз.
7. **Редактировать**
Эта кнопка активирует режим редактирования метаданных.

::: tip Примечание
По умолчанию метаданные доступны только для чтения.
:::
8. **Действия редактирования**
В режиме редактирования отмените или примените изменения. Любое изменение ключа в режиме редактирования автоматически сохраняет предыдущий ключ.
9. **Фильтр переменных**
Это поле фильтрует группы переменных для активации, подчеркивая важность **хорошей первоначальной организации переменных**.
