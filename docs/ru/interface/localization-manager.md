# Локализация

Этот обязательный модуль позволяет настроить языки и пространства имён для вашего проекта.
У вас есть возможность использовать интеллектуальный импорт или настроить языковой сервис вручную.

::: tip Примечание
LSDE поддерживает коды ISO 639-1 или комбинации ISO 639-1 - ISO 3166-1. [Для получения более подробной информации о спецификациях нажмите здесь](/ru/getting-started/introduction#i18n-key-convention)
:::

## Интерфейс {#interface}
<DocImage src="/doc/lsde/doc-lsde-ui-localisations.webp" />

Интерфейс предлагает следующие разделы:
0. **Интеллектуальный импорт** (опционально)
Импортируйте уже существующую структуру папок, организованную следующим образом:
`../folder/lang/namespace.json` => `../locales/en/main.json`

### Настройка языков {#setup-languages}
- **Настройка кодов `ISO 639-1` и `ISO 3166-1`**
Коды языков могут быть объединены в соответствии с двумя спецификациями, например: `en` или `en-US`, `en-GB`.
Эти коды `ISO 639-1 - ISO 3166-1` соответствуют языку, за которым следует его локализация.

**Этот раздел позволяет:**
1. Добавлять/удалять языки
Открывает новое диалоговое окно, в котором вы можете использовать менеджер для поиска и/или удаления языков проекта.
2. Определять основной язык
Этот язык используется в качестве источника в некоторых задачах и является обязательным для работы с программным обеспечением.
4. Просматривать, удалять или изменять порядок языков по вашему желанию.

::: tip Примечание
(Это порядок рендеринга в редакторе.) Это основной язык проекта.
:::

### Пространства имён {#namespace}
3. Это место для создания пространств имён.
Пространство имён просто представляет собой **имя файла, содержащего ключи**. Это так просто.
Пример: `locales/en-GB/main.json`. Здесь пространство имён будет `main`, а ключи файла будут иметь относительные пути.

::: tip Примечание
Вы можете переопределить папки пространств имён или удалить их.
:::
