# Тонкая настройка

Эта функция позволяет вам управлять LLM в реальном времени, в зависимости от активного профиля.
Она позволяет создавать профили с пользовательскими правилами, определяя таким образом, как LSDE передает информацию.
Чрезвычайно универсальная, эта система предлагает вам возможность экспериментировать с различными сценариями и адаптировать директивы под ваши конкретные потребности.
Система разработана для быстрого включения и выключения. Кроме того, вы можете изменять директивы в реальном времени, не затрагивая сохраненные профили.

## Для кого предназначена эта система? {#target-audience}
Эта система предназначена для всех пользователей. Некоторые предпочтут базовые директивы, в то время как другие выберут более динамичный рабочий процесс, полезный, например, для написания квестов или сценариев.

## Интерфейс {#interface}
### Инструменты {#tools}
Откройте для себя основные инструменты для работы с Fine-Tuning.

<DocImage src="/doc/lsde/doc-lsde-ui-finetuning.webp" />

1. **Включить/Отключить Fine-Tuning**
Быстро включите или отключите влияние Fine-Tuning на текущие и будущие задачи, всё в реальном времени.

::: tip Примечание
Иконка и название активного профиля также видны в панели быстрых действий, рядом с иконкой Fine-Tuning.
:::
2. **Вертикальный/Горизонтальный режим**
Позволяет закрепить окно в вертикальном или горизонтальном режиме, таким образом отображая профили в более компактном виде.
3. **Показать/Скрыть список профилей**
Скройте список профилей, чтобы освободить место, или используйте сочетания клавиш для доступа к нему.
### Профили {#profiles}
4. **Создать профиль**
Позволяет создать новый профиль.
5. **Список профилей**
Здесь вы можете выбирать, удалять и изменять профили.
### Конфигурация {#Configuration}
Конфигурация активного профиля
6. **Личная заметка профиля**
Эти заметки никогда не передаются LLM; они служат исключительно для информации пользователя.
7. **Правила, связанные с профилем**
Эти правила дополняют базовые правила LSDE. У вас есть возможность отключить правило по умолчанию в настройках задач.
8. **Директива задачи**
Позволяет обогатить содержимое задачи по умолчанию.
9. **Пользовательские описания**
Эти описания добавляются к метаданным (metas).
LSDE систематически передает метаданные и их описания LLM. Это пространство позволяет добавлять дополнительную информацию к этим описаниям.
10. **Дополнительные опции**
Включите или отключите специфическое поведение LSDE при отправке информации LLM с этим активным профилем.
Наведите курсор на каждый параметр, чтобы просмотреть описание его влияния.
