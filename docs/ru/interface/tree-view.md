# Дерево ключей

Интерфейс LSDE предоставляет четкий и структурированный обзор всех ключей перевода вашего проекта. Разработанный для упрощения их управления, он автоматически адаптирует ключи – будь то импортированные или вновь созданные – к своему оптимизированному внутреннему формату, а затем восстанавливает их в формат, специфичный для вашего проекта, обеспечивая тем самым идеальную совместимость и интеграцию.

::: tip Примечание
Таким образом, файл проекта `.lsde` может быть полностью передан и получен.
:::

Рассмотрим пример `name_space.folderA.folderB.folderC.fileABC`:
- Пути ключей структурированы иерархически, с точками в качестве разделителей. Эта конвенция, аналогичная той, что используется в i18next, облегчает навигацию и идентификацию местоположения и папки каждого ключа. Следует отметить, что i18next по умолчанию использует `name_space:folderA.folderB.folderC.fileABC`.
- Первый сегмент каждого пути (до первой точки) определяет пространство имен (namespace). Крайне важно подчеркнуть, что это пространство имен **неизменяемо** в рамках древовидной структуры.

::: tip Примечание
Для любого изменения пространства имен вам потребуется использовать выделенный интерфейс для управления языками. Этот централизованный подход обеспечивает целостность ваших переводов.
:::

Теперь подробно рассмотрим различные разделы и функциональные возможности интерфейса древовидной структуры ключей.

## Действия в заголовке {#header-actions}
1. **Показать/Скрыть «осиротевшие» ключи.**
Эта опция необходима для поддержания чистоты и актуальности ваших переводов. Она позволяет быстро выявлять ключи, присутствующие в древовидной структуре, но отсутствующие в исходном коде вашего внешнего проекта, что облегчает обнаружение устаревших или неиспользуемых ключей для потенциальной очистки или перемещения.
2. **Показать/Скрыть неполные ключи.**
Эта функция выделяет все ключи, переводы которых отсутствуют на одном или нескольких языках.

::: tip Примечание
**Важное примечание:** Сканер ключей LSDE анализирует только языки, активированные в окне редактора. Деактивированные языки исключаются из процесса анализа, что позволяет сосредоточить проверку на активных языках.
:::

3. **Создать файл или папку.**
Помимо контекстного меню (щелчок правой кнопкой мыши), эта функция позволяет вручную создавать новые ключи или проактивно организовывать вашу древовидную структуру. LSDE поддерживает создание «внутренних» папок, предоставляя вам возможность логически структурировать ключи, включая создание пустых папок для будущих переводов. Эти операции выполняются через интуитивно понятное интерактивное окно, которое ведет вас шаг за шагом.

<DocImage src="/doc/lsde/doc-lsde-ui-createfolder.webp" left />

4. **Поле пространства имен.**
Это поле отображает пространство имен (namespace), где будет создан новый ключ или новая папка, обеспечивая его правильную вставку в существующую иерархию.
5. **Путь ключа.**
Это место предназначено для ввода полного пути ключа. Система предлагает оперативную помощь и мгновенно оповещает, если путь не соответствует правилам форматирования или уникальности, помогая таким образом избежать ошибок.
6. **Переместить выбранные элементы.**
Особенно полезная при создании новой папки, эта опция позволяет одновременно переносить выбранные элементы из древовидной структуры в этот новый каталог. Таким образом, она оптимизирует ваш рабочий процесс и облегчает реорганизацию ключей.
7. **Показать/Скрыть ключи с незавершенными задачами.**
Активируйте эту функцию, чтобы быстро просматривать ключи, связанные с активными задачами или ожидающие подтверждения членом команды. Это ценный актив для отслеживания хода перевода и совместного управления проектами.
8. **Развернуть/Свернуть папки.**
Эта кнопка предлагает два удобных режима навигации в древовидной структуре:
- развернуть все папки для исчерпывающего обзора
- или свернуть их "до активного выбора", чтобы сосредоточиться на конкретном разделе без отвлечения.
