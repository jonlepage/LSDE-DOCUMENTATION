# Глобальные настройки

Здесь вы можете настроить глобальные параметры программного обеспечения LSDE.
Эти параметры будут общими для всех ваших проектов.

---

<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-typo.webp" />

## Типография {#typography}
Типография в основном влияет на текстовые поля редактора и некоторые элементы в настройках заметок.
Интерфейс LSDE имеет частично настраиваемый дизайн UI/UX, но некоторые аспекты остаются фиксированными по причинам дизайна.
Только диалоговые окна могут быть адаптированы к вашей любимой теме.

::: tip Примечание
Эта функция может развиваться со временем, если будет большой спрос.
:::
1. **font size**: размер текста в редакторе и других полях ввода.
2. **font spacing**: межбуквенный интервал в редакторе.
3. **police de charactere**: гарнитура шрифта (font-family), используемая в текстовом редакторе.
4. **haute des ligne**: изменяет высоту строк в редакторе.
5. **couleur**: цвет текста в редакторе.
6. **epaisseur**: позволяет сделать текст более толстым (жирным), если это позволяет гарнитура шрифта.
7. **couleur arriereplan**: определяет цвет фона текстового редактора, независимо от того, активен ли он (в фокусе) или неактивен.
8. **direction du texte**: определяет языки, для которых отображение должно осуществляться справа налево (RTL).

## Wrappers {#wrappers}
<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-wrappers.webp" />

Wrappers — это функции обёртывания, которые можно добавить к системе выделения.
Когда вы выделяете текст в редакторе и используете сочетание клавиш, у вас есть возможность обернуть его символами.
Это поведение, очень популярное в средах разработки (IDE), также поддерживается LSDE.
1. Клавиши, которые активируют обёртывание при выделении текста.
2. Символы для вставки до и после выделенного текста.
3. Количество возможных итераций до удаления обёртывания текста.
4. Если активировано, удаляет пробелы в начале и конце выделенного текста, чтобы разместить их за пределами обёртывания.

## Редактор {#editor}
Этот раздел объединяет различные функции (flags), позволяющие обогатить ваш опыт использования $t(main.words.lsde-title).
Чтобы узнать больше, просто наведите курсор мыши на каждую опцию, чтобы отобразить подробную всплывающую подсказку о ее функции.

## Задачи {#tasks}
Раздел "Задачи" позволяет управлять встроенными задачами LSDE.
Здесь вы найдете правила (rules) и директивы, отправляемые в LLM.

- **Правила (rules)** — это общие и важные инструкции, которые применяются ко всем задачам.
- **Задачи (tasks)** — это более специфичные подправила, отправляемые в LLM для точных операций.

Давайте рассмотрим интерфейс встроенных задач.

<!-- TODO image introuvable : configGlobTaks -->

1. Вы можете отключить ненужные задачи для ваших проектов (например, отключить задачу меню).
2. Кнопка для восстановления встроенной директивы.
3. Кнопка для копирования встроенной директивы.

::: tip Примечание
Недоступно в пробной версии LSDE.
:::
4. Количество слов и оценка стоимости в токенах.
5. Вы можете в любой момент экспортировать файл JSON для анализа примера запроса, отправленного в LLM, и улучшить свой prompt engineering.

::: tip Примечание
Обратите внимание, что не рекомендуется изменять встроенные правила и задачи LSDE.
Следует отдавать предпочтение другим решениям, таким как [fine-tuning](/ru/interface/fine-tuning) или [директивы проекта](/ru/interface/project-settings#llm-directive).
:::

## Аутентификация {#authentication}
Этот раздел предназначен для настройки LLM, как бесплатных, так и доступных через ваши собственные ключи API.
Здесь вы можете ввести ключи API ваших предпочтительных сервисов LLM и защитить их.

::: tip Примечание
Обратите внимание, что некоторые провайдеры, такие как Gemini или ElevenLabs, теперь предлагают бесплатные ключи API с ежемесячными или еженедельными квотами использования.
:::

Для LLM обработки текста доступны 6 провайдеров.
### Для LLM обработки текста {#text-processing-llm}
- Anthropic
- OpenAI
- Mistral
- Gemini
- Deepseek

### LLM для голосов {#voice-llm}
Предлагается ElevenLabs (он также предлагает бесплатные ключи с ежемесячными квотами).

::: tip Примечание
вы должны создать свои голосовые профили на их инструментах
:::

<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-auth.webp" />

Вам просто нужно нажать на `temp-mail` или `10minmail`, чтобы получить временный адрес, затем нажать `open`, чтобы зарегистрировать этот адрес электронной почты.
Таким образом, сессия будет сохранена на последующие дни, что позволит вам пользоваться GPT и пакетными задачами.
Вы также будете подпадать под квоту (в настоящее время, по состоянию на 25 ноября 2025 года, около 70 задач в час), после чего придется подождать.

Когда учетная запись будет удалена OpenAI, процесс придется повторить.

::: tip Примечание
Обратите внимание, что этот сервис следует использовать только для базового тестирования, а не для продакшена. Бесплатная модель GPT имеет более низкое качество и плохо поддерживает функции постобработки ответов, предлагаемые LSDE.
:::

### Интерфейс {#interface}
0. Запоминать ваши ключи API, чтобы избежать их ввода при каждом запуске программы.

::: tip Примечание
ключи зашифрованы, но остаются доступными для злоумышленников
:::
1. Вы можете безопасно зашифровать свои ключи с помощью системы кодирования программного обеспечения.

::: tip Примечание
Ваши ключи будут зашифрованы с использованием уникального идентификатора вашей машины и вашей установки. Они не смогут быть выполнены где-либо, кроме этого экземпляра LSDE.
:::
2. Вы можете получить свой зашифрованный ключ здесь и использовать его в предусмотренных полях вместо стандартных ключей API.
3. Здесь вы должны вставить ключи API ваших провайдеров.
4. Кнопка быстрого доступа к сайту провайдера для просмотра вашего потребления.
5. Выбор доступных моделей для выбранного провайдера.
6. Вы можете добавить свои любимые модели в избранное.

::: tip Примечание
Избранные модели доступны во вкладках LLM в нижнем колонтитуле программы. Щелчок правой кнопкой мыши позволяет быстро переключаться между ними.
:::

### Бесплатный LLM {#free-LLM}
LSDE также предлагает вам бесплатный метод использования GPT через специальный процесс.
Обычно вы захотите использовать этот LLM для выполнения тестов или мини-задач без затрат.
7. Вы можете создать бесплатный аккаунт ChatGPT для тестирования функций программного обеспечения.
Предлагаются два провайдера временных электронных писем.

::: tip Примечание
Не используйте свою официальную учетную запись, чтобы избежать ее закрытия в случае интенсивного использования.
:::
8. Нажмите здесь, чтобы создать аккаунт GPT с вашим временным адресом электронной почты.

::: tip Примечание
Обычно вы можете выполнять пакетную обработку около 70 экземпляров в час.
:::

::: tip Примечание
Некоторые сервисы, такие как Google AI, теперь предлагают бесплатные ключи API с ограниченным количеством запросов в час.
:::
Вы также можете воспользоваться их услугами.

## Доступность {#accessibility}
Этот раздел позволяет настроить языки интерфейса, а также фильтры отображения, полезные, если у вас возникли проблемы с калибровкой экранов или вы страдаете от какой-либо формы дальтонизма.

1. Выбор языков интерфейса: как и на стартовом экране, вы можете переназначить 2 своих предпочтительных языка.
Затем достаточно нажать клавишу [F1], чтобы мгновенно переключаться между двумя интерфейсами.
Эта функция позволяет, например, работать на своем родном языке и в любой момент переключаться на другой язык для общения с коллегой или ознакомления с документацией.
2. Вы можете изменить контраст программного обеспечения здесь.
3. А также оттенок (hue), который позволяет управлять цветовой темой, если у вас есть нарушения зрения.
