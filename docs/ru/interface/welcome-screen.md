# Экран приветствия

Стартовый экран LSDE отображается каждый раз, когда вы запускаете приложение напрямую, не открывая файл проекта из вашего проводника.
Он состоит из трёх основных разделов.

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## Выбор языка интерфейса {#interface-language-choice}
Этот раздел позволяет выбрать язык отображения интерфейса программы.
Используйте клавишу `[F1]` для быстрого переключения между двумя последними выбранными языками.

::: tip Примечание
Эта программа, ориентированная на обучение, позволяет очень быстро переключаться с вашего родного языка на предпочитаемый второй язык.
:::

## Действия при запуске {#startup-actions}
Эти опции позволяют начать проект:
- **Загрузить проект** : Для открытия и загрузки существующих проектов.
- **Новый проект** : Для создания новых проектов, с предустановками или без них.
- **Демонстрация** : Для загрузки демонстрационных проектов, чтобы вдохновиться и изучить различные рабочие процессы.

## Недавние проекты {#recent-projects}
Этот раздел отображает недавно открытые проекты, позволяя быстро вернуться к тем, которые вы используете чаще всего.
