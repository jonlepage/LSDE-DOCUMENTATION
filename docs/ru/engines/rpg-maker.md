# RPG Maker

LSDE нативно интегрируется с **RPG Maker MV** и **RPG Maker MZ** для управления и перевода ваших диалогов.

## Как это работает {#how-it-works}
RPG Maker хранит свои диалоги в файлах JSON (Map, CommonEvents, System и т. д.).
LSDE может импортировать эти файлы, позволяя вам удобно редактировать и переводить их, а затем экспортировать обратно в формат, ожидаемый RPG Maker.

Если вы хотите получить полную поддержку RMMZ i18n, вам необходимо скачать [плагин здесь](https://raw.githubusercontent.com/jonlepage/LSDE-RMMZ-I18N/refs/heads/main/dist/LSDE_i18n.js)

Типичный рабочий процесс:
- **Импорт** — Укажите LSDE путь к папке `data/` вашего проекта RPG Maker. Smart Import автоматически обнаруживает и извлекает ключи диалогов.
- **Редактирование** — Пишите, исправляйте и переводите тексты вручную или с помощью LLM, метаданных и проверки орфографии.
- **Экспорт** — Экспортируйте измененные файлы JSON непосредственно в ваш проект RPG Maker.

## Поддерживаемые версии {#supported-versions}
- **RPG Maker MV** — Полный импорт/экспорт JSON
- **RPG Maker MZ** — Полный импорт/экспорт JSON
- Более старые версии (VX Ace, XP) не поддерживаются нативно, но могут работать через пользовательский парсер.

## Советы {#tips}
- Используйте сканер кода, чтобы убедиться, что все ваши ключи присутствуют в файлах RPG Maker.
- Настройте паттерны Regex в параметрах проекта для автоматического обнаружения ключей диалогов RPG Maker.
- Воспользуйтесь режимом MAD (Multi Actor Dialog), если ваши события содержат диалоги с несколькими персонажами.
