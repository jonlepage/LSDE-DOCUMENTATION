# Godot

LSDE интегрируется с **Godot 4** для управления и перевода ваших диалогов, с нативной поддержкой GDScript и C# (Mono).

## Интеграция {#integration}
Godot использует файлы CSV или JSON для локализации через свою систему `TranslationServer`.
LSDE может импортировать и экспортировать эти форматы для бесперебойного рабочего процесса между двумя инструментами.

Рабочий процесс:
- **Импорт** — Импортируйте ваши файлы перевода Godot (CSV или JSON) в LSDE через Smart Import.
- **Редактирование** — Переводите и редактируйте с помощью LLM, метаданных и проверкой орфографии.
- **Экспорт** — Повторно экспортируйте локализованные файлы непосредственно в папку вашего проекта Godot.

## Генерация кода {#code-generation}
LSDE автоматически генерирует типизированные классы доступа на двух языках:
- **GDScript** — Нативные классы Godot с автодополнением в редакторе Godot.
- **C# (Mono)** — Для проектов Godot, использующих среду выполнения .NET.

Эти классы предоставляют доступ к вашим ключам диалога с проверкой типов, избегая ошибок, связанных с жестко заданными строками.

## Советы {#tips}
- Godot загружает переводы через `TranslationServer.set_locale()` — ваши файлы, экспортированные LSDE, напрямую совместимы.
- Поместите файл `.lsde` в корневую папку вашего проекта Godot для управления версиями с помощью Git.
- Настройте автоматический экспорт при сохранении в LSDE для непрерывной синхронизации ваших изменений с Godot.
- Используйте `tr()` в ваших скриптах GDScript для доступа к экспортированным ключам перевода.
