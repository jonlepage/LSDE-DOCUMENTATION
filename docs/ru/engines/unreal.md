# Unreal Engine

LSDE поддерживает **Unreal Engine** через нативную систему локализации Unreal и генерацию C++ классов.

Рабочий процесс:
- **Импорт** — Экспортируйте ваши тексты из Unreal через Localization Dashboard, затем импортируйте их в LSDE.
- **Редактирование** — Переводите и редактируйте ваши тексты в LSDE с помощью LLM.
- **Экспорт** — Реэкспортируйте локализованные файлы и реимпортируйте их в Unreal.

## Генерация C++ классов {#cpp-generation}
LSDE автоматически генерирует типизированные классы доступа на **C++** из ваших определений blueprints.
Эти классы интегрируются в ваш проект Unreal и позволяют вам получать доступ к вашим диалогам с проверкой типов во время компиляции.

## Советы {#tips}
- Используйте **Localization Dashboard** Unreal для начальной настройки языков и целей локализации.
- Поместите файл `.lsde` в корневой каталог вашего проекта Unreal для контроля версий Git.
- LSDE занимается переводом и композицией — Unreal управляет упаковкой (packaging) и загрузкой во время выполнения через `FText`.
