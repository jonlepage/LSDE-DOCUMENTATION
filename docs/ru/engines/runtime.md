# Runtime (LSDEDE)

Мульти-runtime движок выполнения загружает и выполняет blueprints, экспортированные из редактора.
Доступный на TypeScript, C#, C++ и GDScript, он нативно интегрируется в любой игровой движок или фреймворк.
Архитектура управляется коллбэками, не имеет внешних зависимостей и является фреймворк-агностичной.
