# Runtime (LSDEDE)

The multi-runtime execution engine loads and executes blueprints exported from the editor.
Available in TypeScript, C#, C++, and GDScript, it integrates natively into any game engine or framework.
The architecture is callback-driven, without external dependencies, and is framework-agnostic.

[▶ Consult the official runtime documentation](https://jonlepage.github.io/LS-Dialog-Editor-Engine/)
