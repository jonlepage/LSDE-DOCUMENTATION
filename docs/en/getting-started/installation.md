# Installation

To download [LS-Installer](https://lepasoft.com/en/software/ls-dialog-editor#download), select the version compatible with your operating system. If you choose the compressed version in [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)) format, extract its contents to the folder of your choice.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## What is LS-INSTALLER? {#what-is-lsinstaller}
LS-Installer is an **interactive launcher** designed to facilitate the installation of **Lepasoft** games and software.
To install LS Dialog Editor, simply select it from the list of available products, then follow these steps:
1. Read and accept the terms of use.
2. Choose the installation directory.
3. Start the download.
4. Check the desired post-installation options.
5. Launch the application via its desktop shortcut or directly from the installation folder.

::: tip Note
The installer automatically downloads the latest version of the chosen product.
:::

---

## Problem with LS-Installer? {#issue-with-lsinstaller}
If the launcher does not start, your operating system may be blocking its execution, despite the software's signature.
In this case, download the compressed version instead and perform the extraction manually rather than automatically.
Currently in beta, **the software includes a local signature**, but not yet one validated by the Microsoft Store.

::: tip Note
The installation application is open-source and not obfuscated. It can be disassembled with any decompilation software to view its source code.
Software blocking is common on operating systems like Microsoft Windows and Apple macOS when signatures have not been validated via their paid certification services. Software that has gained a good reputation can sometimes avoid this blocking after several years of existence, even without recurring certification fees.
:::
