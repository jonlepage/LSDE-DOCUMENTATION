# Home screen

LSDE's startup screen appears every time you launch the application directly, without opening a project file from your explorer.
It is organized into three main sections.

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## Interface Language Choice {#interface-language-choice}
This section allows you to choose the display language for the software interface.
Use the `[F1]` key to quickly switch between the last two selected languages.

::: tip Note
The software, with an educational purpose, allows you to switch very quickly from your native language to your preferred second language.
:::

## Startup Actions {#startup-actions}
These options allow you to start a project:
- **Load a project** : To open and load your existing projects.
- **New project** : To create new projects, with or without preconfigurations.
- **Demo** : To load demo projects to inspire you and explore different workflows.

## Recent Projects {#recent-projects}
This section displays recently opened projects, allowing you to quickly resume those you use most often.

---

### The Animated Background {#animated-background}
::: tip Note
The animated background can be disabled via the [global settings](/en/interface/global-settings#editor).
:::
