# Main Screen

The LSDE environment offers a modular and dockable layout system. It allows you to position the different windows in the locations that best suit your work habits. When creating a new project, three windows are already pre-positioned for optimal navigation and editing.

---

## Basic Layouts {#basic-layouts}
### Moving and Positioning Windows {#move-and-place-windows}
0. To move a window, simply drag its tab anywhere within the application interface.
A visual suggestion system will guide you to precisely reposition it to your desired location.
**To display or restore windows, you have two options:**
- Via the top tabs, by accessing the `view => layouts` menu.
- By using the quick buttons located in the top right of the screen.

::: tip Note
The quick window management buttons allow you to instantly display or hide a window, restoring its last state.
:::
### Session Telemetry {#session-telemetry}
LSDE offers a rich interface that should delight users interested in data and statistics management.
This information is largely displayed in the software's footer.

1. Located at the bottom left of the screen, you will find real-time telemetry data related to the current project and session.
These include the estimated number of keys, words, letters, keystrokes, and tokens for the entire project.
2. Following that are detailed information about the selector and cursor in the text editor.
3. Additional information also appears when you hover over certain elements.
4. To the right of this section, quick buttons allow you to activate or deactivate a Language Model (LLM) and quickly change it.

::: tip Note
A right-click with your mouse allows you to switch between your favorite models.
:::
5. Notifications regarding warnings and errors that occurred during your session are also provided.
You can submit them for assistance.
6. Finally, the ZEN mode activation button is also located in this area.
