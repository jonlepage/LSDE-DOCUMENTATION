# Pantalla de inicio

La pantalla de inicio de LSDE aparece cada vez que inicias la aplicación directamente, sin abrir un archivo de proyecto desde tu explorador.
Está organizada en tres secciones principales.

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## Elección del idioma de la interfaz {#interface-language-choice}
Esta sección te permite elegir el idioma de visualización de la interfaz del software.
Utiliza la tecla `[F1]` para alternar rápidamente entre los dos últimos idiomas seleccionados.

::: tip Nota
El software, de vocación educativa, te permite cambiar muy rápidamente de tu idioma nativo a tu segundo idioma preferido.
:::

## Acciones de inicio {#startup-actions}
Estas opciones te permiten iniciar un proyecto:
- **Cargar un proyecto**: Para abrir y cargar tus proyectos existentes.
- **Nuevo proyecto**: Para crear nuevos proyectos, con o sin preconfiguraciones.
- **Demo**: Para cargar proyectos de demostración para inspirarte y explorar diferentes flujos de trabajo.

## Proyectos recientes {#recent-projects}
Esta sección muestra los proyectos abiertos recientemente, permitiéndote retomar rápidamente los que usas con más frecuencia.
