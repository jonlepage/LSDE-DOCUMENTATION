# Pantalla Principal

El entorno de LSDE ofrece un sistema de diseño modular y acoplable. Le permite posicionar las diferentes ventanas en los lugares que mejor se adapten a sus hábitos de trabajo. Al crear un nuevo proyecto, tres ventanas ya están preestablecidas para una navegación y redacción óptimas.

## Disposición básica {#basic-layouts}
### Mover y posicionar ventanas {#move-and-place-windows}
0. Para mover una ventana, simplemente arrastre su pestaña a cualquier parte de la interfaz de la aplicación.
Un sistema de sugerencias visual le guiará para reposicionarla precisamente en el lugar deseado.
**Para mostrar o restaurar ventanas, dispone de dos opciones:**
- A través de las pestañas superiores, accediendo al menú `view => layouts`.
- Utilizando los botones rápidos situados en la parte superior derecha de la pantalla.

::: tip Nota
Los botones rápidos de gestión de ventanas permiten mostrar u ocultar una ventana instantáneamente, restaurando su último estado.
:::
### Telemetría de sesión {#session-telemetry}
LSDE ofrece una interfaz rica que debería deleitar a los usuarios interesados en la gestión de datos y estadísticas.
Esta información se muestra en gran parte en el pie de página del software.

1. Situados en la parte inferior izquierda de la pantalla, encontrará datos de telemetría en tiempo real relacionados con el proyecto y la sesión actual.
Estos incluyen el número de claves, palabras, letras, pulsaciones de teclado y tokens estimados para todo el proyecto.
2. A continuación, se muestra información detallada sobre el selector y el cursor en el editor de texto.
3. También aparece información adicional cuando pasa el cursor sobre ciertos elementos.
4. A la derecha de esta sección, los botones rápidos le permiten activar o desactivar un modelo de lenguaje (LLM) y cambiarlo rápidamente.

::: tip Nota
Un clic derecho con el ratón permite alternar entre sus modelos favoritos.
:::
5. También se comunican notificaciones relativas a advertencias y errores ocurridos durante su sesión.
Puede enviarlas para obtener ayuda.
6. Finalmente, el botón de activación del modo ZEN también se encuentra en esta zona.
