# Instalación

Para descargar [LS-Installer](https://lepasoft.com/es/software/ls-dialog-editor#download), seleccione la versión compatible con su sistema operativo. Si elige la versión comprimida en formato [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)), extraiga su contenido en la carpeta de su elección.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## ¿Qué es LS-INSTALLER? {#what-is-lsinstaller}
LS-Installer es **un lanzador interactivo** diseñado para facilitar la instalación de juegos y software de **Lepasoft**.
Para instalar LS Dialog Editor, solo tiene que seleccionarlo de la lista de productos disponibles y seguir estos pasos:
1. Lea y acepte las condiciones de uso.
2. Elija el directorio de instalación.
3. Inicie la descarga.
4. Marque las opciones de post-instalación deseadas.
5. Inicie la aplicación a través de su acceso directo en el escritorio o directamente desde la carpeta de instalación.

::: tip Nota
El instalador descarga automáticamente la versión más reciente del producto elegido.
:::

---

## ¿Problema con LS-Installer? {#issue-with-lsinstaller}
Si el lanzador no se inicia, es posible que su sistema operativo bloquee su ejecución, a pesar de la firma del software.
En ese caso, descargue la versión comprimida y realice la extracción manualmente en lugar de automáticamente.
Actualmente en fase beta, **el software incluye una firma local**, pero aún no una firma validada por Microsoft Store.

::: tip Nota
La aplicación de instalación es de código abierto (open-source) y no está ofuscada. Puede ser desensamblada con cualquier software de descompilación para visualizar su código fuente.
El bloqueo de software es común en sistemas operativos como Microsoft Windows y Apple macOS cuando las firmas no han sido validadas a través de sus servicios de certificación de pago. Los programas que han adquirido una buena reputación a veces pueden evitar este bloqueo después de varios años de existencia, incluso sin costes de certificación recurrentes.
:::
