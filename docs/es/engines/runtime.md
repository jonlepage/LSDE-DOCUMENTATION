# Runtime (LSDEDE)

El motor de ejecución multi-runtime carga y ejecuta los blueprints exportados desde el editor.
Disponible en TypeScript, C#, C++ y GDScript, se integra de forma nativa en cualquier motor de juego o framework.
La arquitectura está impulsada por callbacks, sin dependencias externas y agnóstica al framework.

[▶ Consulta la documentación oficial del runtime](https://jonlepage.github.io/LS-Dialog-Editor-Engine/)
