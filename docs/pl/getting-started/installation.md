# Instalacja

Aby pobrać [LS-Installer](https://lepasoft.com/pl/software/ls-dialog-editor#download), wybierz wersję kompatybilną z Twoim systemem operacyjnym. Jeśli wybierzesz wersję skompresowaną w formacie [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)), rozpakuj jej zawartość do wybranego folderu.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## Czym jest LS-INSTALLER? {#what-is-lsinstaller}
LS-Installer to **interaktywny instalator** zaprojektowany, aby ułatwić instalację gier i oprogramowania **Lepasoft**.
Aby zainstalować LS Dialog Editor, wystarczy go wybrać z listy dostępnych produktów, a następnie wykonać następujące kroki:
1. Przeczytaj i zaakceptuj warunki użytkowania.
2. Wybierz katalog instalacyjny.
3. Rozpocznij pobieranie.
4. Zaznacz pożądane opcje po instalacji.
5. Uruchom aplikację za pomocą jej skrótu na pulpicie lub bezpośrednio z folderu instalacyjnego.

::: tip Uwaga
Instalator automatycznie pobiera najnowszą wersję wybranego produktu.
:::

---

## Problem z LS-Installer? {#issue-with-lsinstaller}
Jeśli instalator się nie uruchamia, możliwe, że Twój system operacyjny blokuje jego uruchomienie, pomimo podpisu oprogramowania.
W takim przypadku pobierz raczej wersję skompresowaną i rozpakuj ją ręcznie, zamiast automatycznie.
Obecnie w fazie beta, **oprogramowanie zawiera lokalny podpis**, ale nie ma jeszcze podpisu zatwierdzonego przez Microsoft Store.

::: tip Uwaga
Aplikacja instalacyjna jest open-source i nie jest zaciemniona. Można ją zdezasemblować za pomocą dowolnego oprogramowania do dekompilacji, aby zobaczyć jej kod źródłowy.
Blokowanie oprogramowania jest powszechne w systemach operacyjnych takich jak Microsoft Windows i Apple macOS, gdy podpisy nie zostały zatwierdzone za pośrednictwem ich płatnych usług certyfikacyjnych. Oprogramowanie, które zyskało dobrą reputację, może czasami uniknąć tej blokady po kilku latach istnienia, nawet bez ponoszenia cyklicznych opłat za certyfikację.
:::
