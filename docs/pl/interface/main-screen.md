# Ekran główny

Środowisko LSDE oferuje modułowy i dokowalny system układu. Pozwala on na rozmieszczenie różnych okien w miejscach, które najlepiej odpowiadają Twoim nawykom pracy. Podczas tworzenia nowego projektu trzy okna są już wstępnie rozmieszczone, aby zapewnić optymalną nawigację i pisanie.

## Układy podstawowe {#basic-layouts}
### Przenoszenie i pozycjonowanie okien {#move-and-place-windows}
0. Aby przenieść okno, po prostu przeciągnij jego zakładkę w dowolne miejsce interfejsu aplikacji.
Wizualny system sugestii poprowadzi Cię, aby precyzyjnie umieścić je w wybranej lokalizacji.
**Aby wyświetlić lub przywrócić okna, dostępne są dwie opcje:**
- Za pomocą górnych zakładek, przechodząc do menu `view => layouts`.
- Używając szybkich przycisków umieszczonych w prawym górnym rogu ekranu.

::: tip Uwaga
Szybkie przyciski zarządzania oknami umożliwiają natychmiastowe wyświetlenie lub ukrycie okna, przywracając jego ostatni stan.
:::
### Telemetria sesji {#session-telemetry}
LSDE oferuje bogaty interfejs, który powinien zachwycić użytkowników zainteresowanych zarządzaniem danymi i statystykami.
Większość tych informacji jest wyświetlana w stopce oprogramowania.

1. W lewym dolnym rogu ekranu znajdziesz dane telemetryczne w czasie rzeczywistym dotyczące bieżącego projektu i sesji.
Obejmują one liczbę kluczy, słów, liter, uderzeń klawiszy i szacowanych tokenów dla całego projektu.
2. Następnie pojawiają się szczegółowe informacje dotyczące selektora i kursora w edytorze tekstu.
3. Dodatkowe informacje pojawiają się również po najechaniu myszą na niektóre elementy.
4. Po prawej stronie tej sekcji znajdują się szybkie przyciski, które umożliwiają aktywację lub dezaktywację modelu językowego (LLM) oraz szybką jego zmianę.

::: tip Uwaga
Kliknięcie prawym przyciskiem myszy umożliwia przełączanie między ulubionymi modelami.
:::
5. Powiadomienia dotyczące ostrzeżeń i błędów, które wystąpiły podczas Twojej sesji, są również komunikowane.
Możesz je przesłać, aby uzyskać pomoc.
6. Wreszcie, przycisk aktywacji trybu ZEN znajduje się również w tej strefie.
