# Runtime (LSDEDE)

Silnik wykonawczy multi-runtime ładuje i wykonuje blueprinty eksportowane z edytora.
Dostępny w TypeScript, C#, C++ i GDScript, integruje się natywnie z dowolnym silnikiem gry lub frameworkiem.
Architektura jest oparta na callbackach, bez zewnętrznych zależności i jest agnostyczna wobec frameworka.
