# Runtime (LSDEDE)

मल्टी-रनटाइम निष्पादन इंजन एडिटर से निर्यात किए गए ब्लूप्रिंट को लोड और निष्पादित करता है।
यह TypeScript, C#, C++ और GDScript में उपलब्ध है, और किसी भी गेम इंजन या फ्रेमवर्क में मूल रूप से एकीकृत हो जाता है।
आर्किटेक्चर कॉलबैक-आधारित है, जिसमें कोई बाहरी निर्भरता नहीं है और यह फ्रेमवर्क-अज्ञेयवादी है।
