# स्थापना

[LS-Installer](https://lepasoft.com/hi/software/ls-dialog-editor#download) डाउनलोड करने के लिए, अपने ऑपरेटिंग सिस्टम के साथ संगत संस्करण चुनें। यदि आप [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)) फॉर्मेट में संपीड़ित संस्करण चुनते हैं, तो उसकी सामग्री को अपनी पसंद के फ़ोल्डर में निकालें।

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## LS-INSTALLER क्या है? {#what-is-lsinstaller}
LS-Installer **एक इंटरैक्टिव लॉन्चर** है जिसे **Lepasoft** गेम्स और सॉफ्टवेयर की स्थापना को आसान बनाने के लिए डिज़ाइन किया गया है।
LS Dialog Editor स्थापित करने के लिए, बस इसे उपलब्ध उत्पादों की सूची से चुनें, फिर इन चरणों का पालन करें:
1. उपयोग की शर्तों को पढ़ें और स्वीकार करें।
2. इंस्टॉलेशन डायरेक्टरी चुनें।
3. डाउनलोड शुरू करें।
4. इच्छित पोस्ट-इंस्टॉलेशन विकल्पों को चुनें।
5. एप्लिकेशन को डेस्कटॉप पर उसके शॉर्टकट के माध्यम से या सीधे इंस्टॉलेशन फ़ोल्डर से लॉन्च करें।

::: tip नोट
इंस्टॉलर स्वचालित रूप से चुने गए उत्पाद का नवीनतम संस्करण डाउनलोड करता है।
:::

---

## LS-Installer के साथ समस्या? {#issue-with-lsinstaller}
यदि लॉन्चर शुरू नहीं होता है, तो हो सकता है कि आपके ऑपरेटिंग सिस्टम ने सॉफ्टवेयर के हस्ताक्षर के बावजूद उसके निष्पादन को अवरुद्ध कर दिया हो।
इस स्थिति में, इसके बजाय संपीड़ित संस्करण डाउनलोड करें और स्वचालित रूप से करने के बजाय मैन्युअल रूप से निष्कर्षण करें।
वर्तमान में बीटा चरण में, **सॉफ्टवेयर में एक स्थानीय हस्ताक्षर शामिल है**, लेकिन Microsoft Store द्वारा मान्य हस्ताक्षर अभी तक नहीं है।

::: tip नोट
इंस्टॉलेशन एप्लिकेशन ओपन-सोर्स है और अस्पष्ट नहीं है। इसके सोर्स कोड को देखने के लिए इसे किसी भी डीकंपाइलेशन सॉफ्टवेयर से डिसअसेंबल किया जा सकता है।
Microsoft Windows और Apple macOS जैसे ऑपरेटिंग सिस्टम पर सॉफ्टवेयर को ब्लॉक करना आम बात है जब हस्ताक्षरों को उनकी सशुल्क प्रमाणन सेवाओं के माध्यम से मान्य नहीं किया गया हो। अच्छी प्रतिष्ठा प्राप्त करने वाले सॉफ्टवेयर कई वर्षों के अस्तित्व के बाद इस अवरोधन से बच सकते हैं, भले ही आवर्ती प्रमाणन शुल्क न हो।
:::
