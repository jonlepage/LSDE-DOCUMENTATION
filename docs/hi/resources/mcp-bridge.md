# MCP Bridge

MCP ब्रिज सर्वर बाहरी AI उपकरणों और एजेंटों को मानक MCP (Model Context Protocol) प्रोटोकॉल के माध्यम से एडिटर के साथ इंटरैक्ट करने की अनुमति देता है।

## MCP क्या है? {#what-is-mcp}
MCP एक खुला प्रोटोकॉल है जो भाषा मॉडल और AI एजेंटों को बाहरी एप्लिकेशन के साथ संचार करने की अनुमति देता है।
आपका IDE (VS Code, Cursor, आदि) आपके AI असिस्टेंट की क्षमताओं को समृद्ध करने के लिए एक MCP सर्वर से स्वचालित रूप से कनेक्ट हो सकता है।
कनेक्शन आपके प्रोजेक्ट के रूट में रखी गई `.mcp.json` कॉन्फ़िगरेशन फ़ाइल के माध्यम से होता है — किसी मैन्युअल इंस्टॉलेशन की आवश्यकता नहीं है।

## कॉन्फ़िगरेशन {#configuration}
सर्वर जोड़ने के लिए अपने प्रोजेक्ट के रूट में `.mcp.json` फ़ाइल बनाएं या संपादित करें:
```json
{
	"mcpServers": {
		"lsde": {
			"command": "npx",
			"args": ["-y", "@lsde/mcp-server@latest"],
			"env": {
				"LSDE_MCP_PORT": "9225"
			}
		}
	}
}
```
एक बार यह फ़ाइल स्थापित हो जाने पर, सर्वर का पता लगाने के लिए अपने IDE (या AI एक्सटेंशन) को पुनरारंभ करें।
प्रक्रिया पूरी तरह से स्वचालित है: पैकेज `npx` के माध्यम से डाउनलोड किया जाता है और सर्वर पृष्ठभूमि में चलता है।

[npm पैकेज: @lsde/mcp-server](https://www.npmjs.com/package/@lsde/mcp-server)

## क्षमताएं {#capabilities}
MCP ब्रिज सर्वर बाहरी एजेंटों को इसकी अनुमति देता है:
- **प्रोजेक्ट संरचना पढ़ें** — दृश्यों, ब्लॉक, कनेक्शन और मेटाडेटा का ट्री।
- **नोड्स देखें** — ग्राफ के किसी भी नोड के टेक्स्ट और गुणों तक पहुंचें।
- **वेरिएबल प्रबंधित करें** — प्रोजेक्ट के वेरिएबल और डिक्शनरी को पढ़ें और उनके साथ इंटरैक्ट करें।
- **दृश्य जनरेशन ट्रिगर करें** — संरचित कमांड के माध्यम से नए दृश्य बनाएं।
- **संशोधन प्रस्तावित करें** — सत्यापन के लिए टेक्स्ट या संरचना के संपादन सबमिट करें।

## उपयोग के मामले {#use-cases}
- **Claude Code / Cursor** — AI-सहायता प्राप्त विकास वर्कफ़्लो में एडिटर को एकीकृत करें।
- **स्वचालित पाइपलाइन** — एडिटर को अपने बिल्ड या CI/CD स्क्रिप्ट से कनेक्ट करें।
- **QA एजेंट** — अपने संवादों की कथात्मक संगति को स्वचालित रूप से मान्य करें।
- **कस्टम उपकरण** — मानक प्रोटोकॉल के माध्यम से अपने स्वयं के एकीकरण बनाएं।

## उपलब्धता {#availability}
MCP ब्रिज **प्रोफेशनल** और **एंटरप्राइज/एजुकेशनल** योजनाओं में उपलब्ध है।
