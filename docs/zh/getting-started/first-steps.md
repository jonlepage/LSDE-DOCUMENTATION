# 第一步

## 开始 {#getting-started}
首次启动软件时，**您将被提示开始试用期**或输入您的许可证密钥。
- **试用期：**
试用期允许您在规定时间内使用所有功能测试软件。

::: tip 备注
在 Beta 阶段，试用期是无限的，并将在该阶段结束后重置。
:::

- **许可证：**
如果您拥有许可证，请输入以解锁软件。

::: tip 备注
您的密钥已在交易时通过电子邮件发送给您。
在软件的 Beta 期间，您无法购买密钥。
:::

## 界面语言选择 {#interface-language-choice}
LSDE 在启动时提供 3 个主要选项：

## 加载项目 {#load-project}
<DocImage src="/doc/lsde/lsde-banner.webp" h="30" left icon />

您可以选择一个扩展名为 `.lsde` 的文件。

::: tip 备注
如果文件关联已安装，在文件浏览器中双击 .lsde 文件可以直接打开项目。
:::

## 新建项目 {#new-project}
此选项允许您创建新项目，并预配置某些项目类型的设置。
您还可以预安装 Steam 上最流行的语言。
请注意，这些预配置不是最终的；它们可以在项目内部随时修改。

::: tip 备注
将您的项目保存在 Git 或其他系统支持的文件夹中。.lsde 文件不包含任何敏感数据。
:::
在屏幕底部，您还会找到最近打开的项目列表，让您能够快速恢复工作会话。

## 演示项目 {#demo-project}
软件中包含一些演示项目。它们允许您观察某些功能的实际运行情况或为您的工作流程获取灵感。

# 强制配置 {#mandatory-configuration}
为了充分利用 LSDE 并开始您的工作，您必须完成初始配置的第一步。
此步骤快速且必不可少，可解锁软件中特定于您项目的所有功能。

位于快速窗口菜单右上角的本地化管理窗口图标将闪烁，以指示需要重要信息。

进入本地化管理窗口后，您需要：
- 导入您项目中已包含语言文件和目录的现有文件夹。
- 或者手动添加语言和命名空间 (`namespace`)。

然后，选择项目的主要语言，您就可以开始使用 LSDE 了。
有关本地化管理器的更多信息，[请参阅此部分](/zh/interface/localization-manager)
