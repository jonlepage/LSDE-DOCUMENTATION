# 翻译

## 如何翻译 {#how-to-translate}
::: tip 备注
LSDE 提供强大的工具，让我们能够翻译成世界上所有的语言。
:::
LLM（“Large Language Models”，大语言模型）是人类设计的数学架构，只要提供合适的上下文，它们在翻译方面表现出色。
 默认会为发送给 LLM 的每个请求提供上下文，这确保了结果更具相关性。

::: tip 备注
注意：虽然结果令人满意且能显著降低制作成本，但仍必须寻求专业工作室进行最终审核。
:::

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-1.webp" />

要使用 LSDE 翻译对话，首先通过语言管理器在项目中添加支持的语言。

1. 打开 [i18n 本地化配置](/zh/interface/localization-manager#patterns) 窗口。
2. 点击指示的按钮为项目添加语言。
3. 选择所需的语言以及项目的主语言。
选项采用 `ISO 639-1` 和 `ISO 3166-1` 格式。

添加语言后，请确保正确设置项目的主语言。这一步对于解锁软件的大部分操作至关重要。

::: tip 备注
虽然主语言理想情况下应该是确定的，但可以随时修改。
:::

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-2.webp" left />

1. 接着在树状结构中选择一个键。此选择将在编辑器主窗口中显示所有相关的对话。
2. 之后您可以过滤想要处理的语言。

::: tip 备注
右键点击可以快速在显示所有语言或仅显示主语言之间切换。
:::

## 使用 LLM 翻译 {#translate-with-llm}
<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-3.webp" />

1. 首先在编辑器中点击一个对话以启用编辑。
将会出现一个图标，允许通过菜单管理所需任务。

默认情况下， 提供已配置好的任务。
在这种情况下，我们将使用“翻译”任务。

::: tip 备注
如果需要，可以在全局设置中重新配置可用任务。
:::
2. 选择翻译任务。

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-4.webp" />

配置窗口将打开以调整任务详情：
1. 可以在启动前启用或禁用某些过滤器。
2. 调整迭代深度（如果处理对象是文件夹）。
3. 根据当前参数显示/隐藏忽略的键。
4. 如果自动设置不足，可以手动启用/禁用要包含的实例。
5. 添加额外指令以引导 LLM。

::: tip 备注
使用键盘上的上/下箭头浏览您的全局历史记录。
:::

设置完成后，点击“确认”（右下角）。

::: tip 备注
任务一旦创建，就会发送到自动处理系统。系统会在项目打开时立即激活，以恢复进行中的任务。
:::

---

分配给任务的所有实例都将切换到对比模式，以便在左侧查看原始文本，在右侧查看回复。

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-5.webp" left />

1. 此按钮显示相对于原始文本增加的字母数量。

::: tip 备注
它还允许显示或隐藏增加的 Token。
:::
2. 此按钮显示移除的字母数量。

::: tip 备注
它还允许显示或隐藏删除的 Token。
:::
3. 此按钮显示最终的全局状态（字符净增减）。

::: tip 备注
如果您通过点击相关文本部分取消更改，它还允许切换到最终渲染效果。
:::
4. 修改渲染：您可以点击每个标签来取消不需要的更改。
5. 您可以根据需要多次迭代，向 LLM 发送额外指令。

::: tip 备注
注意：根据所使用的模型，缓存并非总是自动进行的，这可能会导致成本呈指数级增长，因为每次迭代都会重新发送整个历史记录。
:::
6. 遥测：显示 LLM 提供商返回的 Token 成本。
7. 优化完成后，用于接受或拒绝更改的按钮。
8. “Experimental”（实验性）：允许根据某些场景添加自动修复（例如：如果 LLM 在后续对话中未返回原始文本）。
9. 在更改历史记录中导航以返回到之前的版本。
