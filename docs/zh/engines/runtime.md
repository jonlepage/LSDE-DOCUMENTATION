# Runtime (LSDEDE)

多运行时执行引擎加载并执行从编辑器导出的蓝图。
它支持 TypeScript、C#、C++ 和 GDScript，可原生集成到任何游戏引擎或框架中。
其架构由回调驱动，无外部依赖，且与框架无关。
