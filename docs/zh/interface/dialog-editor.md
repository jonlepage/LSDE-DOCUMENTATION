# 对话编辑器

本节介绍键的渲染内容。编辑器垂直且递归地组织所选键，显示其所有语言的内容、上下文及其子键。
它提供了导航和渲染选项以筛选语言和上下文，以及操作和遥测工具。

## 渲染系统 {#rendering-system}
LSDE 拥有一个“后处理”渲染系统，用于自定义文本显示，从而方便阅读和编写。
配置正则表达式（Regex）模式以捕获文本组并为其指定装饰。
这些捕获可以与变量关联，以向译者、作者或大型语言模型（LLM）提供额外信息。
[访问有关渲染和模式创建的高级部分](/zh/features/rendering)

## 标题工具 {#header-tools}
1.  **启用/禁用后渲染**
    快速禁用模式渲染。
2.  **导航**
    用于在下一个和上一个键之间快速导航的按钮。
3.  **创建键**
    快速创建新键。
4.  **显示/隐藏上下文**
    显示或隐藏与键相关的上下文以简化视图。
    每个图标对应于已配置上下文的标签。
5.  **显示/隐藏语言**
    筛选语言以同时工作。
    > 这些筛选器也被 LSDE 用于其他系统操作，从而影响其他诊断工具。

## 编辑区域 {#editing-zones}
此区域显示活动语言的文本以及键的当前任务。
6.  **在树形结构中选择键**
    在树形结构中定位并选择键。
    > 用于编辑元数据，仅在活动键上可用。
7.  **任务**
    一个菜单提供了适用于此键、其关系及其子键的任务。
8.  **保护**
    勾选此框可将文本标记为最终且受保护，从而忽略某些任务和操作。
    禁用此选项将建议禁用与此键相关的所有其他语言的验证。
0.  **键**
    显示键的完整路径，**采用 LSDE 格式**

## 查找/替换 {#search-replace}
8.  **查找/替换**
    [CTRL+F] 打开内部搜索工具。
    它提供了一个 Regex 模式以应对复杂情况。
    也可以通过上下文菜单启动搜索。

## 性能 {#performance}
默认情况下，LSDE 会在非活动窗口中禁用复杂的渲染（widgets）。
这确保了视觉体验和低延迟之间的良好平衡。
如果性能不是问题，请在全局配置中禁用此优化。

::: tip 备注
如果同时显示多种语言，可能会消耗资源，因为渲染系统是按键分段的。
:::
