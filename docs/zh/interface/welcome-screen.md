# 主屏幕

LSDE 启动屏幕会在您每次直接启动应用程序，而不是从文件管理器打开项目文件时显示。
它分为三个主要部分。

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## 选择界面语言 {#interface-language-choice}
此部分允许您选择软件界面的显示语言。
使用 `[F1]` 键可快速切换最近选择的两种语言。

::: tip 备注
该软件旨在用于教育目的，可让您非常快速地从母语切换到您喜欢的第二语言。
:::

## 启动操作 {#startup-actions}
这些选项允许您启动项目：
- **加载项目**：用于打开和加载现有项目。
- **新建项目**：用于创建新项目，可选择带或不带预配置。
- **演示**：用于加载演示项目，以获取灵感并探索不同的工作流程。

## 最近项目 {#recent-projects}
此部分显示最近打开的项目，让您可以快速恢复最常使用的项目。

---

### 动态背景 {#animated-background}
::: tip 备注
动态背景可通过[全局设置](/zh/interface/global-settings#editor)禁用。
:::
