# 元数据

元数据窗口允许向键添加额外信息，这些信息可分发给该键及其子键。

## 为什么要使用元数据？ {#why-use-metas}
在执行任务时，这些信息会集成到 LLM 的请求中。
填写的信息也可以随时在元数据显示器中查看。
视图是递归的，从上到下，从活动键到项目命名空间的根。

::: tip 备注
您的源项目不应依赖于元数据。元数据纯粹用于提供信息，只应影响文本编写和思考。
:::

**这些信息可以提供以下优势：**
- 帮助翻译人员/撰稿人理解上下文。
- 递归地可视化信息，从键的父级开始。
- 为 LLM 添加相关信息，以便处理键或相邻键。

::: tip 备注
对于同一文件夹中的键，LLM 也会读取相邻键以理解叙事流。
:::
- 在键树中自定义图标和颜色，以便更好地识别。
- 添加图片以视觉化地语境化对话。
- 激活/停用 LLM 可使用的变量。

## 元数据界面 {#metas-interface}
<DocImage src="/doc/lsde/doc-lsde-ui-metadata.webp" />

0. **递归**
限制检索的信息范围，从活动键到其层级父级。
1. **描述 (LLM)**
当键发送给 LLM 时会考虑此信息。它语境化了键的归属、其周围环境及其子键的角色。
2. **允许的变量**
允许添加要由 LLM 处理的变量，以优化其任务。例如，允许角色变量并要求 LLM 仅在任务文件夹中包含这些角色。附加角色可以由 LLM 重新分配/删除，或用于构建额外的交互。
3. **语音变量**
如果已配置语音变量组，请在此处分配对话者。

::: tip 备注
LLM 也可以优先使用它们来验证对话。
:::
4. **用户笔记**
在此处为作曲家、翻译人员或您自己编写备忘录和提示。

::: tip 备注
LLM 无法访问这些内容。由于笔记集成到 .lsde 文件中，如果通过 Git 共享或版本控制，请避免包含敏感信息。
:::
5. **图片**
显示图片以语境化文件夹或键。对于没有源代码访问权限或预览的翻译人员来说非常有用。

::: tip 备注
图片在 .lsde 文件中会被压缩和降级，以便于共享。
:::
6. **亲属关系**
这些部分递归地显示父级信息，从上到下。
7. **编辑**
此按钮激活元数据编辑模式。

::: tip 备注
默认情况下，元数据是只读的。
:::
8. **编辑操作**
在编辑模式下，取消或应用更改。在编辑模式下更改任何键会自动保存上一个键。
9. **变量筛选器**
此框筛选要激活的变量组，强调了**良好初始变量组织的重要性**。
