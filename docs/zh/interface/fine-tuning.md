# 微调

此功能允许您根据活动配置文件实时控制 LLM。
它允许您创建具有自定义规则的配置文件，从而定义 LSDE 传输信息的方式。
该系统功能极其多样，让您可以尝试各种场景并根据您的特定需求调整指令。
该系统设计用于快速启用和禁用。此外，您可以实时修改指令，而不会影响您保存的配置文件。

## 该系统适用于哪些人群？ {#target-audience}
该系统专为所有用户设计。有些人会倾向于基本指令，而另一些人则会选择更动态的工作流程，例如在编写任务或场景时会很有用。

## 界面 {#interface}
### 工具 {#tools}
探索使用 Fine-Tuning 的主要工具。

<DocImage src="/doc/lsde/doc-lsde-ui-finetuning.webp" />

1. **启用/禁用 Fine-Tuning**
实时快速启用或禁用 Fine-Tuning 对当前和未来任务的影响。

::: tip 备注
活动配置文件的图标和名称也会显示在快速操作栏中，就在 Fine-Tuning 图标旁边。
:::
2. **垂直/水平模式**
允许将窗口固定为垂直或水平模式，从而以更紧凑的形式显示配置文件。
3. **显示/隐藏配置文件列表**
隐藏配置文件列表以释放空间，或使用键盘快捷键访问它。
### 配置文件 {#profiles}
4. **创建配置文件**
允许创建新配置文件。
5. **配置文件列表**
您可以在此处选择、删除和修改配置文件。
### 配置 {#Configuration}
活动配置文件配置
6. **配置文件个人备注**
这些备注绝不会传输给 LLM；它们仅用于为用户提供信息。
7. **与配置文件相关的规则**
这些规则是对 LSDE 基本规则的补充。您可以选择在任务选项中禁用默认规则。
8. **任务指令**
允许丰富默认任务的内容。
9. **自定义描述**
这些描述会添加到元数据（metas）中。
LSDE 会系统地将元数据及其描述传输给 LLM。此空间允许您为这些描述添加补充信息。
10. **额外选项**
启用或禁用在此配置文件激活时，LSDE 在向 LLM 发送信息时的特定行为。
将鼠标悬停在每个参数上以显示其影响的描述。
