# 主屏幕

LSDE 环境提供了一个模块化且可停靠的布局系统。它允许您将不同的窗口放置在最符合您工作习惯的位置。创建新项目时，会预设三个窗口，以实现最佳导航和编辑体验。

## 基本布局 {#basic-layouts}
### 移动和定位窗口 {#move-and-place-windows}
0. 要移动窗口，只需将其选项卡拖动到应用程序界面的任何位置。
一个可视化的提示系统将引导您将其精确地重新定位到所需位置。
**要显示或恢复窗口，您有两种选择：**
- 通过顶部选项卡，访问 `view => layouts` 菜单。
- 使用屏幕右上角的快速按钮。

::: tip 备注
窗口管理快速按钮可让您立即显示或隐藏窗口，并恢复其上次状态。
:::
### 会话遥测 {#session-telemetry}
LSDE 提供了一个丰富的界面，应该会让对数据和统计管理感兴趣的用户感到满意。
这些信息主要显示在软件的页脚。

1. 在屏幕左下方，您会找到与当前项目和会话相关的实时遥测数据。
这包括整个项目的估计键数、字数、字母数、键盘敲击次数和令牌数。
2. 接下来是文本编辑器中选择器和光标的详细信息。
3. 当您将鼠标悬停在某些元素上时，也会出现补充信息。
4. 在此部分的右侧，快速按钮允许您激活或停用语言模型 (LLM) 并快速更改它。

::: tip 备注
右键单击鼠标可让您在喜欢的模型之间切换。
:::
5. 还会显示有关您会话期间发生的警告和错误的通知。
您可以将其提交以获取帮助。
6. 最后，ZEN 模式激活按钮也位于此区域。
