# 钥匙树

LSDE 界面为您项目的所有翻译键提供清晰、结构化的概览。该界面旨在简化翻译键的管理，它会自动将翻译键（无论是导入的还是新创建的）调整为优化的内部格式，然后将其还原为您项目特定的格式，从而确保完美的兼容性和集成。

::: tip 备注
因此，`.lsde` 项目文件可以完整地共享和恢复。
:::

以 `name_space.folderA.folderB.folderC.fileABC` 为例：
- 键的路径以分层方式构建，使用点作为分隔符。这种约定类似于 i18next，有助于导航和识别每个键的位置和文件夹。值得注意的是，i18next 默认使用 `name_space:folderA.folderB.folderC.fileABC`。
- 每个路径的第一个片段（在第一个点之前）定义了命名空间 (namespace)。重要的是要强调，此命名空间在树结构中是**不可变的**。

::: tip 备注
对于命名空间的任何修改，您都需要使用专门的语言管理界面。这种集中式方法确保了翻译的完整性。
:::

现在，让我们详细探讨键树界面的各个部分和功能。

## 页眉操作 {#header-actions}
1. **显示/隐藏孤立键。**
此选项对于保持翻译的整洁和相关性至关重要。它允许快速识别树结构中存在但外部项目源代码中不存在的键，从而便于检测过时或未使用的键，以便进行潜在的清理或重新定位。
2. **显示/隐藏不完整键。**
此功能突出显示所有在一种或多种语言中缺少翻译的键。

::: tip 备注
**重要提示：** LSDE 的键扫描器仅分析编辑器窗口中已启用的语言。已禁用的语言将排除在分析过程之外，从而可以将验证集中在活动语言上。
:::

3. **创建文件或文件夹。**
除了上下文菜单（右键单击）之外，此功能还允许手动创建新键或主动组织您的树结构。LSDE 支持创建“内部”文件夹，让您能够逻辑地构建键，包括为未来的翻译创建空文件夹。这些操作通过一个直观的交互式窗口逐步引导您完成。

<DocImage src="/doc/lsde/doc-lsde-ui-createfolder.webp" left />

4. **命名空间字段。**
此字段显示将创建新键或新文件夹的命名空间，确保其正确插入到现有层次结构中。
5. **键路径。**
此位置保留用于输入键的完整路径。系统提供实时帮助，并在路径不符合格式或唯一性规则时立即发出警报，从而帮助您避免错误。
6. **移动选定项。**
在创建新文件夹时特别有用，此选项允许同时将树结构中选定的元素传输到此新目录。这优化了您的工作流程并简化了键的重新组织。
7. **显示/隐藏具有进行中任务的键。**
激活此功能可快速查看与活动任务相关或等待团队成员验证的键。这对于跟踪翻译进度和协作项目管理来说是一项宝贵的资产。
8. **展开/折叠文件夹。**
此按钮在树结构中提供两种便捷的导航模式：
- 展开所有文件夹以获取全面概览
- 或“折叠到活动选择”以专注于特定部分而不受干扰。
