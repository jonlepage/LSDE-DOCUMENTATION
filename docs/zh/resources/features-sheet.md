# 特性列表

公开 Beta 版本为支持各类项目带来了用户体验 (UX) 和功能的重大改进。
以下是功能摘要 (Cheat Sheet)：

## 常规 {#general}
- 非常紧凑、现代且符合人体工程学的界面。
- 界面已完整翻译为 10 种语言：fr, en, es, de, it, pl, ja, ko, zh, ru。
- 通过 `[F1]` 在两个首选语言之间快速切换界面。
- 模块化布局系统，支持窗口停靠（非常适合多显示器）。
- 所有窗口均支持全屏模式。
- 悬停在所有按钮上均有帮助提示 (Tooltips)。
- 无障碍：专为色盲和视力障碍提供的选项。
- 针对快速操作的上下文快捷键。
- 多种禅意 (Zen) 模式，提升写作时的专注度。
- 实时项目统计：键名 (keys)、单词、字符、Token、击键次数、选择。
- 一键式引导和预配置的快速项目创建。
- 兼容版本控制 (Git) 且易于共享的 JSON 格式 `.lsde` 项目文件。
- 操作系统 (OS) 图标支持及 `.lsde` 后缀文件关联。
- 自动重新打开上次使用的项目选项。
- 最近打开项目的历史记录 (History)。
- 意外关闭检测及会话恢复。
- 独立导入/导出 LSDE 全局配置配置文件 (Profile)。
- 一键启用/禁用及切换 LLM 模型。
- 支持免费、匿名、无需账号或 API 密钥的原生备用 (fallback) LLM。
- 支持 LLM Copilot：Claude, DeepSeek, Gemini, GPT, Mistral, Ollama, ElevenLabs...
- 支持通过 `localhost` 使用本地 LLM。
- 基于文档训练的集成式 LLM 助手，为您提供指导。
- 配置字段的 LLM 辅助菜单：帮助、填充、改进、翻译。
- 内部错误和警告的诊断与管理器。
- 在线提供完整的 LSDE 和 i18n 文档。
- 支持在外部（浏览器）或内部 (LSDE) 打开链接。
- 针对以下引擎的预配置：Unity, Godot, RPG Maker, Unreal Engine, GameMaker, Construct3, Cocos2d, Phaser, Babylon.js, SugarCube, NovelStudio...
- 可自定义的 i18n 上下文管理器：复数、性别、布尔值等。

## 开发者 {#dev}
- 代码库分析系统，用于自动引用键名。
- RAW 扫描器，用于识别可能需要 i18n 键名的原始文本。
- 针对自研游戏引擎的预配置及可自定义 RegEx。
- 支持动态键名（例如：`game:.scenes.${index}.events.1`）。
- 自动创建键名，支持上下文检测和默认文本。
- 已检测但尚未创建的键名的显示过滤器。
- 双击即可在 IDE 中精确打开键名所在的代码行。
- 控制显示的代码行数。
- 源代码显示主题。
- 实时检测和可视化 i18n 文件的外部失步 (desynchronization)。
- 一键手动同步选项。

## 树状视图 {#tree}
- 多种渲染模式：树状、扁平列表（包含或不包含完整路径）、缺失翻译、无引用的键名、带音频或带有正在进行的任务。
- 按键名或关联内容搜索。
- 优化的命名空间 (root) 文件夹设计，便于快速识别。
- 选择时显示子文件夹数量。
- 根据选择自动递增的智能 i18n 键名创建。
- 完整的右键上下文菜单。
- `Ctrl+点击` 多选。
- 支持拖放 (Drag & Drop)。
- 每个条目上的上下文标签：复数、性别、语音、未完成、代码中未知等。
- 通过上下文菜单对子文件夹进行批量 (batch) 迭代任务。

## LLM {#LLM}
- 常用模型管理器。
- API 密钥安全管理。
- 支持保存多个 API 密钥，并在出错时自动轮换 (auto-roll)。
- 原生任务的管理与自定义：发送给 LLM 的指令和规则。

## 编辑 / 创作 {#editing}
- 主题和排版自定义：字体、间距、行高、颜色及 RTL 支持。
- 100% 可自定义的文本渲染引擎：变量、颜色、链接、工具提示。
- 过滤要显示的语言和上下文。
- 支持 RegEx 的文本搜索、替换和导航。
- 针对每条对话的任务菜单：翻译、校对、重写、长度调整、续写。
- 实时可配置的 LLM 拼写检查器。
- 快速操作栏：导航、渲染管理、上下文或键名创建。
- 通过双换行的段落模式选项。
- 快速删除行（IDE 行为）。
- 选中文本时的上下文菜单。
- 可自定义的包装器 (wrappers) 管理器，用于包裹选中的文本。
- 根据交互次数递增且可逆的包装器。
- 验证系统：检测更改、待重新验证或忽略的翻译。
- 任务期间的修改对比和结果微调。
- 记忆每类任务的快速配置。
- 支持 SAD/MAD (Single/Multi Actor Per Dialog) 范式。
- 每个字符串的各角色语音（音频）管理器。
- 元数据可视化：图片、笔记、LLM 上下文、角色、语音、图标。
- 显示依赖变量和文本引用。
