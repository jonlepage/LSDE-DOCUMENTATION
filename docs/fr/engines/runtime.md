# Runtime (LSDEDE)

Le moteur d'exécution multi-runtime charge et exécute les blueprints exportés depuis l'éditeur.
Disponible en TypeScript, C#, C++ et GDScript, il s'intègre nativement dans n'importe quel moteur de jeu ou framework.
L'architecture est pilotée par callbacks, sans dépendance externe et agnostique au framework.
