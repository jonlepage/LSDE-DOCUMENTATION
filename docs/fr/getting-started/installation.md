# Installation

Pour télécharger [LS-Installer](https://lepasoft.com/fr/software/ls-dialog-editor#download), sélectionnez la version compatible avec votre système d'exploitation. Si vous choisissez la version compressée au format [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)), extrayez-en le contenu dans le dossier de votre choix.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## Qu'est-ce que LS-INSTALLER ? {#what-is-lsinstaller}
LS-Installer est **un lanceur interactif** conçu pour faciliter l'installation des jeux et logiciels **Lepasoft**.
Pour installer LS Dialog Editor, il suffit de le sélectionner dans la liste des produits disponibles, puis de suivre ces étapes :
1. Lisez et acceptez les conditions d'utilisation.
2. Choisissez le répertoire d'installation.
3. Lancez le téléchargement.
4. Cochez les options post-installation souhaitées.
5. Lancez l'application via son raccourci sur le bureau ou directement depuis le dossier d'installation.

::: tip Note
L'installateur télécharge automatiquement la version la plus récente du produit choisi.
:::

---

## Problème avec LS-Installer ? {#issue-with-lsinstaller}
Si le lanceur ne se lance pas, il est possible que votre système d'exploitation bloque son exécution, malgré la signature du logiciel.
Dans ce cas, téléchargez plutôt la version compressée et effectuez l'extraction manuellement plutôt qu'automatiquement.
Actuellement en phase bêta, **le logiciel inclut une signature locale**, mais pas encore de signature validée par le Microsoft Store.

::: tip Note
L'application d'installation est open-source et n'est pas obfusquée. Elle peut être désassemblée avec n'importe quel logiciel de décompilation pour visualiser son code source.
Le blocage de logiciels est courant sur les systèmes d'exploitation comme Microsoft Windows et Apple macOS lorsque les signatures n'ont pas été validées via leurs services de certification payants. Les logiciels ayant acquis une bonne réputation peuvent parfois éviter ce blocage après plusieurs années d'existence, même sans frais de certification récurrents.
:::
