# Ecran d'acceuil

L'écran de démarrage de LSDE s'affiche chaque fois que vous lancez l'application directement, sans ouvrir un fichier de projet depuis votre explorateur.
Il est organisé en trois sections principales.

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## Choix de la langue d'interface {#interface-language-choice}
Cette section vous permet de choisir la langue d'affichage de l'interface du logiciel.
Utilisez la touche `[F1]` pour basculer rapidement entre les deux dernières langues sélectionnées.

::: tip Note
Le logiciel, à vocation éducative, vous permet de passer très rapidement de votre langue natale à votre seconde langue préférée.
:::

## Actions de démarrage {#startup-actions}
Ces options vous permettent de démarrer un projet :
- **Charger un projet** : Pour ouvrir et charger vos projets existants.
- **Nouveau projet** : Pour créer de nouveaux projets, avec ou sans préconfigurations.
- **Démo** : Pour charger des projets de démonstration afin de vous inspirer et d'explorer différents workflows.

## Projets récents {#recent-projects}
Cette section affiche les projets récemment ouverts, vous permettant de reprendre rapidement ceux que vous utilisez le plus souvent.

---

### L'arrière-plan animé {#animated-background}
::: tip Note
L'arrière-plan animé peut être désactivé via les [paramètres globaux](/fr/interface/global-settings#editor).
:::
