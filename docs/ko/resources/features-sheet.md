# 기능 시트

공개 베타 버전은 모든 유형의 프로젝트를 지원하기 위해 사용자 경험(UX) 및 기능 면에서 대대적인 개선을 이루었습니다.
다음은 주요 기능 요약(Cheat Sheet)입니다:

## 일반 {#general}
- 매우 컴팩트하고 현대적이며 인체공학적인 인터페이스.
- 10개 언어로 완벽하게 번역된 인터페이스: fr, en, es, de, it, pl, ja, ko, zh, ru.
- `[F1]` 키를 통한 두 가지 선호 언어 간의 빠른 인터페이스 전환.
- 도킹 가능한 창이 포함된 모듈식 레이아웃 시스템 (멀티 모니터 환경에 이상적).
- 모든 창에 대한 전체 화면 모드.
- 모든 버튼 마우스 오버 시 도움말 툴팁 제공.
- 접근성: 색맹 및 시각 장애인을 위한 전용 옵션.
- 컨텍스트별 빠른 작업을 위한 단축키.
- 집필 중 집중력을 높여주는 여러 가지 Zen 모드.
- 실시간 프로젝트 통계: 키, 단어, 글자 수, 토큰(tokens), 키 입력, 선택 영역.
- 클릭 한 번으로 가이드에 따라 사전 설정된 프로젝트 빠른 생성.
- 버전 관리(Git)와 호환되고 공유가 쉬운 JSON 형식의 `.lsde` 프로젝트 파일.
- `.lsde` 확장자 아이콘 및 프로젝트 열기에 대한 OS 지원.
- 마지막으로 사용한 프로젝트 자동 재오픈 옵션.
- 최근 열었던 프로젝트 히스토리.
- 세션 복구 기능을 포함한 예기치 않은 종료 감지.
- LSDE 글로벌 설정 프로필 개별 가져오기/내보내기.
- 클릭 한 번으로 LLM 모델 활성화/비활성화 및 변경.
- 계정이나 API 키가 필요 없는 무료 익명 네이티브 폴백(fallback) LLM 지원.
- LLM 코파일럿 지원: Claude, DeepSeek, Gemini, GPT, Mistral, Ollama, ElevenLabs...
- `localhost`를 통한 로컬 LLM 지원.
- 가이드를 위해 문서를 학습한 내장 LLM 어시스턴트.
- 설정 필드 내 LLM 지원 메뉴: 도움말, 채우기, 개선, 번역.
- 내부 오류 및 경고 진단 및 관리자.
- 온라인에서 사용 가능한 전체 LSDE 및 i18n 문서.
- 외부(브라우저) 또는 내부(LSDE) 링크 열기 지원.
- 다음을 위한 사전 설정 제공: Unity, Godot, RPG Maker, Unreal Engine, GameMaker, Construct3, Cocos2d, Phaser, Babylon.js, SugarCube, NovelStudio...
- 커스터마이징 가능한 i18n 컨텍스트 관리자: 복수형, 성별, 불리언(booleans) 등.

## 개발자 {#dev}
- 자동 키 참조를 위한 코드베이스 분석 시스템.
- i18n 키가 필요할 수 있는 가공되지 않은 텍스트(raw text) 식별을 위한 RAW 스캐너.
- 자체 제작 게임 엔진을 위한 커스텀 가능하고 사전 설정된 RegEx.
- 동적 키 지원 (예: `game:.scenes.${index}.events.1`).
- 컨텍스트 및 기본 텍스트 감지를 통한 키 자동 생성.
- 감지되었으나 아직 생성되지 않은 키 전용 표시 필터.
- 소스 코드 내 키의 정확한 위치로 IDE를 여는 더블 클릭 기능.
- 표시되는 소스 코드 라인 수 제어.
- 소스 코드 표시 테마.
- i18n 파일의 외부 비동기화 실시간 감지 및 시각화.
- 클릭 한 번으로 수동 동기화 옵션.

## 트리 구조 {#tree}
- 다중 렌더링 모드: 트리 구조, 플랫 리스트 (전체 경로 포함/미포함), 누락된 번역, 참조 없는 키, 오디오 포함 또는 진행 중인 작업 포함.
- 키 또는 관련 내용으로 검색.
- 빠른 식별을 위해 최적화된 네임스페이스(root) 폴더 디자인.
- 선택 시 하위 폴더 수 표시.
- 선택 영역에 따른 자동 증분 기능이 포함된 지능형 i18n 키 생성.
- 우클릭을 통한 전체 컨텍스트 메뉴.
- `Ctrl+클릭`을 통한 다중 선택.
- 드래그 앤 드롭(Drag & Drop) 지원.
- 각 항목의 컨텍스트 태그: 복수형, 성별, 음성, 미완성, 코드 내 알 수 없음 등.
- 하위 폴더 반복 작업을 위한 컨텍스트 메뉴 기반 배치(batch) 작업.

## LLM {#LLM}
- 선호 모델 관리자.
- 안전한 API 키 관리.
- 오류 발생 시 자동 순환(auto-roll) 기능을 포함한 여러 API 키 저장 가능.
- 네이티브 작업 관리 및 커스터마이징: LLM에 전송되는 지침 및 규칙.

## 편집 / 작성 {#editing}
- 테마 및 타이포그래피 커스터마이징: 글꼴, 간격, 줄 높이, 색상 및 RTL 지원.
- 100% 커스터마이징 가능한 텍스트 렌더링 엔진: 변수, 색상, 링크, 툴팁.
- 표시할 언어 및 컨텍스트 필터링.
- RegEx를 지원하는 텍스트 검색, 교체 및 탐색.
- 각 대화 처리를 위한 작업 메뉴: 번역, 수정, 문구 수정, 길이 조정, 텍스트 이어 쓰기.
- 실시간 설정 가능한 LLM 맞춤법 검사기.
- 빠른 실행 바: 탐색, 렌더링 관리, 컨텍스트 또는 키 생성.
- 이중 줄 바꿈을 통한 단락 모드 옵션.
- 빠른 라인 삭제 (IDE 동작 방식).
- 텍스트 선택 시 컨텍스트 메뉴.
- 선택한 텍스트를 감싸는 커스터마이징 가능한 래퍼(wrappers) 관리자.
- 상호작용 횟수에 따른 증분 및 가역적 래퍼.
- 유효성 검사 시스템: 변경 사항 감지, 재확인 필요 또는 무시할 번역.
- 작업 중 수정 사항 비교 및 결과 미세 조정.
- 각 작업 유형별 빠른 설정 저장.
- SAD/MAD (Single/Multi Actor Per Dialog) 패러다임 지원.
- 각 스트링별 캐릭터별 음성(오디오) 관리자.
- 메타데이터 시각화: 이미지, 메모, LLM 컨텍스트, 캐릭터, 음성, 아이콘.
- 종속 변수 및 텍스트 참조 표시.
