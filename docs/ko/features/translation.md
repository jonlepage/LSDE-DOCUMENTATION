# 번역

## 번역 방법 {#how-to-translate}
::: tip 참고
LSDE는 전 세계 모든 언어로 번역할 수 있는 강력한 도구를 제공합니다.
:::
LLM(거대 언어 모델)은 인간이 설계한 수학적 아키텍처로, 적절한 문맥이 제공될 경우 번역 작업에서 뛰어난 성능을 발휘합니다.
는 기본적으로 LLM에 전달되는 각 요청에 문맥을 제공하여 더욱 관련성 높은 결과를 보장합니다.

::: tip 참고
결과가 만족스럽고 생산 비용을 크게 절감할 수 있지만, 최종 검수를 위해 전문 스튜디오의 도움을 받는 것은 여전히 필수적입니다.
:::

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-1.webp" />

LSDE로 대화를 번역하려면, 먼저 언어 관리자를 통해 프로젝트에서 지원할 언어를 추가하는 것부터 시작합니다.

1. [i18n 로컬라이제이션 설정](/ko/interface/localization-manager#patterns) 창을 엽니다.
2. 표시된 버튼을 통해 프로젝트에 언어를 추가합니다.
3. 원하는 언어와 프로젝트의 기본 언어를 선택합니다.
제공되는 옵션은 `ISO 639-1` 및 `ISO 3166-1` 형식입니다.

언어를 추가한 후에는 프로젝트의 기본 언어를 올바르게 설정해야 합니다. 이 단계는 소프트웨어의 대부분의 기능을 활성화하는 데 필수적입니다.

::: tip 참고
기본 언어는 가급적 확정된 것이 좋지만, 언제든지 수정할 수 있습니다.
:::

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-2.webp" left />

1. 그런 다음 트리 구조에서 키를 선택합니다. 이 선택을 통해 편집기 기본 창에 모든 관련 대화가 표시됩니다.
2. 그 다음 작업하려는 언어를 필터링할 수 있습니다.

::: tip 참고
마우스 오른쪽 버튼을 클릭하면 모든 언어 표시와 기본 언어 표시 사이를 빠르게 전환할 수 있습니다.
:::

---

## LLM으로 번역하기 {#translate-with-llm}
<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-3.webp" />

1. 먼저 편집기에서 대화를 클릭하여 편집 모드를 활성화합니다.
아이콘이 나타나며, 메뉴를 통해 원하는 작업을 관리할 수 있습니다.

기본적으로 는 이미 구성된 작업을 제안합니다.
이 사례에서는 *Traduire*(번역) 작업을 사용합니다.

::: tip 참고
필요한 경우 글로벌 설정에서 가용한 작업을 재구성할 수 있습니다.
:::
2. 번역 작업을 선택합니다.

---

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-4.webp" />

작업 세부 사항을 조정할 수 있는 설정 창이 열립니다:
1. 시작 전 특정 필터를 활성화 또는 비활성화할 수 있습니다.
2. 반복 깊이 조절 (폴더 단위 처리 시).
3. 현재 설정에 따라 무시된 키 표시/숨기기.
4. 자동 설정이 충분하지 않은 경우 포함할 인스턴스를 수동으로 활성화/비활성화합니다.
5. LLM을 가이드하기 위한 추가 지침(directives) 추가.

::: tip 참고
키보드의 위/아래 화살표를 사용하여 글로벌 히스토리를 탐색하세요.
:::

설정을 마친 후, 오른쪽 하단의 *Confirmer*(확인)를 클릭합니다.

::: tip 참고
작업이 생성되는 즉시 자동 처리 시스템으로 전송됩니다. 시스템은 프로젝트가 열리는 즉시 활성화되어 진행 중인 작업을 재개합니다.
:::

---

작업에 할당된 모든 인스턴스는 비교 모드로 전환되어, 왼쪽에는 원본 텍스트를, 오른쪽에는 응답 내용을 시각화하여 확인할 수 있습니다.

<DocImage src="/doc/lsde/doc-lsde-features-howtotranslate-5.webp" left />

1. 이 버튼은 원본 텍스트 대비 추가된 글자 수를 표시합니다.

::: tip 참고
또한 추가된 토큰을 표시하거나 숨길 수 있습니다.
:::
2. 이 버튼은 제거된 글자 수를 표시합니다.

::: tip 참고
또한 삭제된 토큰을 표시하거나 숨길 수 있습니다.
:::
3. 이 버튼은 최종 글로벌 상태(글자 수의 양수 또는 음수 잔액)를 표시합니다.

::: tip 참고
또한 텍스트의 해당 부분을 클릭하여 변경 사항을 취소할 경우 최종 렌더링으로 전환할 수 있습니다.
:::
4. 변경 사항 렌더링: 각 태그를 클릭하여 원치 않는 변경을 취소할 수 있습니다.
5. LLM에 추가 지침을 보내 필요한 만큼 반복할 수 있습니다.

::: tip 참고
사용하는 모델에 따라 캐싱이 체계적이지 않을 수 있으며, 매 반복마다 전체 히스토리가 다시 전송되므로 비용이 기하급수적으로 증가할 수 있습니다.
:::
6. Télémétrie(텔레메트리): LLM 제공업체가 반환한 토큰 비용을 표시합니다.
7. 조정이 완료된 후 변경 사항을 수락하거나 거부하는 버튼입니다.
8. *Experimental*(실험적 기능): 특정 시나리오(예: 대화 연속 시 LLM이 원본 텍스트를 반환하지 않는 경우)에 따라 자동 수정을 추가할 수 있습니다.
9. 이전 버전으로 돌아가기 위한 변경 히스토리 탐색.
