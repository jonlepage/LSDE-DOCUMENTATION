# Runtime (LSDEDE)

멀티 런타임 실행 엔진은 에디터에서 내보낸 블루프린트를 로드하고 실행합니다.
TypeScript, C#, C++, GDScript로 사용 가능하며, 모든 게임 엔진이나 프레임워크에 기본으로 통합됩니다.
이 아키텍처는 콜백 기반이며, 외부 종속성이 없고 프레임워크에 독립적입니다.
