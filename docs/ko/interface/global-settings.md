# 글로벌 설정

여기에서 LSDE 소프트웨어의 전역 설정을 구성할 수 있습니다.
이 설정은 모든 프로젝트와 공유됩니다.

---

<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-typo.webp" />

## 글꼴 {#typography}
글꼴은 주로 편집기의 텍스트 영역과 노트 옵션의 일부 요소에 영향을 미칩니다.
LSDE의 인터페이스는 부분적으로 사용자 정의 가능한 UI/UX 디자인을 가지고 있지만, 일부 측면은 디자인상의 이유로 고정되어 있습니다.
대화 상자만 선호하는 테마에 맞게 조정할 수 있습니다.

::: tip 참고
이 기능은 요청이 많으면 시간이 지남에 따라 발전할 수 있습니다.
:::
1. **글꼴 크기** : 편집기 및 기타 입력 영역의 텍스트 크기입니다.
2. **글자 간격** : 편집기 내 글자 사이의 간격입니다.
3. **글꼴** : 텍스트 편집기에서 사용되는 글꼴(font-family)입니다.
4. **줄 간격** : 편집기에서 줄 높이를 수정합니다.
5. **색상** : 편집기 내 텍스트 색상입니다.
6. **두께** : 글꼴이 지원하는 경우 텍스트를 더 두껍게(굵게) 만듭니다.
7. **배경색** : 활성(포커스) 또는 비활성 텍스트 편집기의 배경색을 정의합니다.
8. **텍스트 방향** : 오른쪽에서 왼쪽(RTL)으로 표시되어야 하는 언어를 정의합니다.

## 래퍼 {#wrappers}
<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-wrappers.webp" />

래퍼는 선택 시스템에 추가할 수 있는 감싸기 동작입니다.
편집기에서 텍스트를 선택하고 키보드 단축키를 사용할 때, 해당 텍스트를 기호로 감쌀 수 있는 옵션이 있습니다.
개발 환경(IDE)에서 매우 인기 있는 이 동작은 LSDE에서도 지원됩니다.
1. 텍스트가 선택되었을 때 래핑을 트리거할 키입니다.
2. 선택한 텍스트 앞뒤에 삽입할 문자입니다.
3. 텍스트 래핑이 제거되기 전에 가능한 반복 횟수입니다.
4. 활성화된 경우, 선택한 텍스트의 시작과 끝에 있는 공백을 제거하여 래핑 외부로 다시 배치합니다.

## 에디터 {#editor}
이 섹션은 $t(main.words.lsde-title) 사용 경험을 풍부하게 하는 다양한 기능(플래그)을 모아 놓은 곳입니다.
자세한 내용을 알아보려면 각 옵션 위에 마우스를 올리면 해당 기능에 대한 자세한 정보 팁이 표시됩니다.

## 작업 {#tasks}
'작업' 섹션에서는 LSDE의 기본 작업을 관리할 수 있습니다.
여기에서 LLM에 전송되는 규칙(rules)과 지침(directives)을 찾을 수 있습니다.

- **규칙(rules)**은 모든 작업에 적용되는 일반적이고 중요한 지침입니다.
- **작업(tasks)**은 특정 작업을 위해 LLM으로 전송되는 더 구체적인 하위 규칙입니다.

기본 작업 인터페이스를 살펴보겠습니다.

<!-- TODO image introuvable : configGlobTaks -->

1. 프로젝트에 불필요한 작업(예: 메뉴 작업 비활성화)을 비활성화할 수 있습니다.
2. 기본 지시문을 복원하는 버튼입니다.
3. 기본 지시문을 복사하는 버튼입니다.

::: tip 참고
LSDE 평가판에서는 사용할 수 없습니다.
:::
4. 단어 수 및 예상 토큰 비용입니다.
5. LLM으로 전송된 요청 예시를 분석하고 프롬프트 엔지니어링을 개선하기 위해 언제든지 JSON 파일을 내보낼 수 있습니다.

::: tip 참고
LSDE의 기본 규칙 및 작업을 수정하는 것은 권장되지 않습니다.
[파인튜닝](/ko/interface/fine-tuning) 또는 [프로젝트 지침](/ko/interface/project-settings#llm-directive)과 같은 다른 솔루션을 사용하는 것이 좋습니다.
:::

## 인증 {#authentication}
이 섹션은 무료 또는 자체 API 키를 통해 접근 가능한 LLM을 구성하는 데 사용됩니다.
여기에서 선호하는 LLM 서비스의 API 키를 입력하고 보호할 수 있습니다.

::: tip 참고
Gemini 또는 ElevenLabs와 같은 일부 공급업체는 이제 월별 또는 주별 사용 할당량이 있는 무료 API 키를 제공합니다.
:::

텍스트 처리 LLM의 경우 6개의 공급업체를 사용할 수 있습니다.
### 텍스트 처리 LLM용 {#text-processing-llm}
- Anthropic
- OpenAI
- Mistral
- Gemini
- Deepseek

### 음성 LLM용 {#voice-llm}
ElevenLabs를 사용할 수 있습니다 (월별 할당량이 있는 무료 키도 제공합니다).

::: tip 참고
해당 도구에서 음성 프로필을 생성해야 합니다.
:::

<DocImage src="/doc/lsde/doc-lsde-ui-glsetting-auth.webp" />

임시 주소를 얻으려면 `temp-mail` 또는 `10minmail`을 클릭한 다음, `open`을 클릭하여 이 이메일을 저장하기만 하면 됩니다.
이렇게 하면 세션이 다음 날까지 저장되어 GPT 및 배치 작업을 이용할 수 있습니다.
또한 할당량(현재 2025년 11월 25일 기준, 시간당 약 70개 작업)이 적용되며, 그 후에는 기다려야 합니다.
OpenAI에서 계정이 삭제되면 이 과정을 다시 반복해야 합니다.

::: tip 참고
이 서비스는 기본적인 테스트용으로만 사용해야 하며, 프로덕션 용도로는 사용하지 않는 것이 좋습니다. GPT의 무료 모델은 품질이 낮고 LSDE에서 제공하는 응답 후 개선 기능을 잘 지원하지 않습니다.
:::

### 인터페이스 {#interface}
0. 소프트웨어 시작 시마다 API 키를 입력할 필요가 없도록 저장합니다.

::: tip 참고
키는 인코딩되어 있지만 악의적인 사용자에게 노출될 수 있습니다.
:::
1. 소프트웨어의 인코딩 시스템을 통해 키를 안전하게 암호화할 수 있습니다.

::: tip 참고
키는 사용자의 컴퓨터 및 설치의 고유 식별자로 암호화됩니다. 이 LSDE 인스턴스 외에서는 실행할 수 없습니다.
:::
2. 여기에서 암호화된 키를 검색하여 표준 API 키 대신 지정된 필드에 사용할 수 있습니다.
3. 여기에 공급업체의 API 키를 삽입해야 합니다.
4. 소비량을 확인하기 위한 공급업체 웹사이트로의 빠른 액세스 버튼입니다.
5. 선택한 공급업체에 사용할 수 있는 모델 선택입니다.
6. 선호하는 모델을 즐겨찾기에 추가할 수 있습니다.

::: tip 참고
즐겨찾기 모델은 소프트웨어 바닥글의 LLM 탭에서 접근할 수 있습니다. 마우스 오른쪽 클릭으로 모델 간에 빠르게 전환할 수 있습니다.
:::

### 무료 LLM {#free-LLM}
LSDE는 또한 특별한 프로세스를 통해 GPT를 무료로 사용할 수 있는 방법을 제공합니다.
일반적으로 비용 없이 테스트 또는 소규모 작업을 수행하기 위해 이 LLM을 사용하게 될 것입니다.
7. 소프트웨어 기능을 테스트하기 위해 무료 ChatGPT 계정을 생성할 수 있습니다.
두 가지 임시 이메일 공급업체가 제안됩니다.

::: tip 참고
과도한 사용 시 계정이 폐쇄될 위험이 있으므로 공식 계정을 사용하지 마십시오.
:::
8. 여기를 클릭하여 임시 이메일로 GPT 계정을 생성하십시오.

::: tip 참고
일반적으로 시간당 약 70개의 인스턴스에 대한 배치 처리를 수행할 수 있습니다.
:::

::: tip 참고
Google AI와 같은 일부 서비스는 이제 시간당 제한된 수의 요청으로 무료 API 키를 제공합니다.
:::
이들의 서비스도 이용할 수 있습니다.

## 접근성 {#accessibility}
이 섹션에서는 인터페이스 언어와 디스플레이 필터를 구성할 수 있습니다. 이는 화면 보정 문제나 색맹이 있는 경우 유용합니다.

1. 인터페이스 언어 선택: 시작 화면에서와 같이 선호하는 두 가지 언어를 다시 지정할 수 있습니다.
이후 [F1] 키를 누르면 두 인터페이스 사이를 즉시 전환할 수 있습니다.
이 기능은 예를 들어, 모국어로 작업하다가 동료와 소통하거나 문서를 참조하기 위해 언제든지 다른 언어로 전환할 수 있도록 합니다.
2. 여기에서 소프트웨어의 대비를 변경할 수 있습니다.
3. 시각 장애가 있는 경우 색상 테마를 관리할 수 있는 색조(hue)도 변경할 수 있습니다.
