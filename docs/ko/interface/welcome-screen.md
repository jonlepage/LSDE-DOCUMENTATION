# 시작 화면

LSDE 시작 화면은 탐색기에서 프로젝트 파일을 열지 않고 앱을 직접 실행할 때마다 표시됩니다.
세 가지 주요 섹션으로 구성되어 있습니다.

---

<DocImage src="/doc/lsde/doc-lsde-startscreen.webp" />

## 인터페이스 언어 선택 {#interface-language-choice}
이 섹션에서는 소프트웨어 인터페이스의 표시 언어를 선택할 수 있습니다.
`[F1]` 키를 사용하여 마지막으로 선택한 두 언어 사이를 빠르게 전환할 수 있습니다.

::: tip 참고
교육용 소프트웨어로서, 모국어에서 선호하는 제2 외국어로 아주 빠르게 전환할 수 있습니다.
:::

## 시작 작업 {#startup-actions}
다음 옵션을 통해 프로젝트를 시작할 수 있습니다:
- **프로젝트 로드** : 기존 프로젝트를 열고 로드합니다.
- **새 프로젝트** : 사전 구성 유무에 관계없이 새 프로젝트를 생성합니다.
- **데모** : 영감을 얻고 다양한 워크플로우를 탐색하기 위해 데모 프로젝트를 로드합니다.

## 최근 프로젝트 {#recent-projects}
이 섹션에는 최근에 열었던 프로젝트가 표시되어, 가장 자주 사용하는 프로젝트를 빠르게 다시 시작할 수 있습니다.
