# 현지화

이 필수 모듈을 통해 프로젝트의 언어와 네임스페이스를 구성할 수 있습니다.
스마트 임포트를 사용하거나 언어 서비스를 수동으로 구성할 수 있습니다.

::: tip 참고
LSDE는 ISO 639-1 코드 또는 ISO 639-1 - ISO 3166-1 조합을 지원합니다. [사양에 대한 자세한 내용은 여기를 클릭하십시오](/ko/getting-started/introduction#i18n-key-convention)
:::

## 인터페이스 {#interface}
<DocImage src="/doc/lsde/doc-lsde-ui-localisations.webp" />

인터페이스는 다음 섹션을 제공합니다:
0. **스마트 임포트** (선택 사항)
다음과 같이 구성된 기존 폴더 구조를 임포트합니다:
`../folder/lang/namespace.json` => `../locales/en/main.json`

### 언어 구성 {#setup-languages}
- **`ISO 639-1` 및 `ISO 3166-1` 코드 구성**
언어 코드는 두 가지 사양에 따라 연결될 수 있습니다. 예를 들어, `en` 또는 `en-US`, `en-GB`입니다.
이러한 `ISO 639-1 - ISO 3166-1` 코드는 언어와 그 지역화를 나타냅니다.

**이 섹션에서는 다음을 수행할 수 있습니다:**
1. 언어 추가/삭제
프로젝트 언어를 찾거나 삭제하는 데 사용할 관리자를 열 수 있는 새 대화 상자를 엽니다.
2. 기본 언어 정의
이 언어는 특정 작업에서 소스로 사용되며 소프트웨어 작업에 필수적입니다.
4. 원하는 순서로 언어를 시각화, 삭제 또는 재정렬합니다.

::: tip 참고
(이것은 편집기에서 렌더링되는 순서입니다.) 이것은 프로젝트의 기본 언어입니다.
:::

### 네임스페이스 {#namespace}
3. 이곳은 네임스페이스를 생성하는 곳입니다.
네임스페이스는 단순히 **키가 포함된 파일의 이름**을 나타냅니다. 그만큼 간단합니다.
예: `locales/en-GB/main.json`. 여기에서 네임스페이스는 `main`이 되고 파일의 키는 상대 경로를 갖습니다.

::: tip 참고
네임스페이스 폴더를 재정의하거나 삭제할 수 있습니다.
:::
