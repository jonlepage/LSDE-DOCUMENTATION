# 메타데이터

메타데이터 창을 통해 키와 그 자식들에게 배포할 수 있는 추가 정보를 키에 추가할 수 있습니다.

## 메타데이터를 사용하는 이유 {#why-use-metas}
작업을 실행할 때, 이 정보는 LLM 요청에 통합됩니다.
입력된 정보는 메타데이터 뷰어에서 언제든지 확인할 수 있습니다.
뷰는 현재 활성 키부터 프로젝트 네임스페이스의 루트까지 위에서 아래로 재귀적으로 표시됩니다.

::: tip 참고
소스 프로젝트는 메타데이터에 의존해서는 안 됩니다. 메타데이터는 순전히 정보 제공의 목적을 가지며, 작성 및 사고에만 영향을 미쳐야 합니다.
:::

**이 정보는 다음과 같은 장점을 제공할 수 있습니다:**
- 번역가/작성자가 맥락을 이해하는 데 도움을 줍니다.
- 키의 상위 관계에서부터 정보를 재귀적으로 시각화합니다.
- 키 또는 인접 키 처리를 위해 LLM에 관련 정보를 추가합니다.

::: tip 참고
동일한 폴더에 있는 키의 경우, LLM은 내러티브 흐름을 이해하기 위해 인접 키도 읽습니다.
:::
- 더 나은 식별을 위해 키 트리에서 아이콘과 색상을 사용자 지정합니다.
- 대화를 시각적으로 맥락화하기 위해 이미지를 추가합니다.
- LLM이 사용할 수 있는 변수를 활성화/비활성화합니다.

---

## 메타데이터 인터페이스 {#metas-interface}
<DocImage src="/doc/lsde/doc-lsde-ui-metadata.webp" />

0. **재귀**
활성 키부터 계층적 상위 요소까지 검색되는 정보 범위를 제한합니다.
1. **설명 (LLM)**
키가 LLM으로 전송될 때 고려되는 정보입니다. 키의 소속, 주변 환경 및 자식의 역할을 맥락화합니다.
2. **허용된 변수**
LLM이 작업을 최적화하기 위해 처리할 변수를 추가할 수 있습니다. 예를 들어, 캐릭터 변수를 허용하고 LLM에 퀘스트 폴더에 해당 캐릭터만 포함하도록 요청할 수 있습니다. 추가 캐릭터는 LLM에 의해 재할당/삭제되거나 추가 상호작용을 구성하는 데 사용될 수 있습니다.
3. **음성 변수**
음성 변수 그룹이 구성된 경우 여기에 대화 상대를 할당합니다.

::: tip 참고
LLM은 대화를 확인하기 위해 우선적으로 이를 사용할 수도 있습니다.
:::
4. **사용자 노트**
작곡가, 번역가 또는 자신을 위한 메모와 비망록을 여기에 작성하십시오.

::: tip 참고
LLM은 여기에 접근할 수 없습니다. 노트는 .lsde 파일에 통합되므로, Git을 통해 공유되거나 버전 관리되는 경우 민감한 정보는 피하십시오.
:::
5. **이미지**
폴더 또는 키를 맥락화하기 위해 이미지를 표시합니다. 소스 코드 또는 미리 보기에 접근할 수 없는 번역가에게 매우 유용합니다.

::: tip 참고
이미지는 .lsde 파일 내에서 압축되고 품질이 저하되어 공유를 용이하게 합니다.
:::
6. **상위 관계**
이 섹션은 상위 요소의 정보를 위에서 아래로 재귀적으로 표시합니다.
7. **편집**
이 버튼은 메타데이터 편집 모드를 활성화합니다.

::: tip 참고
기본적으로 메타데이터는 읽기 전용입니다.
:::
8. **편집 작업**
편집 모드에서 변경 사항을 취소하거나 적용합니다. 편집 모드에서 키를 변경하면 이전 키가 자동으로 저장됩니다.
9. **변수 필터**
이 상자는 활성화할 변수 그룹을 필터링하며, **변수의 초기 조직화가 얼마나 중요한지** 강조합니다.
