# 대화 편집기

이 섹션에서는 렌더링된 키 콘텐츠를 소개합니다. 에디터는 선택된 키를 수직적이고 재귀적으로 구성하며, 모든 언어, 해당 컨텍스트 및 하위 키의 콘텐츠를 표시합니다.
언어 및 컨텍스트를 필터링하는 탐색 및 렌더링 옵션은 물론, 액션 및 원격 분석 도구를 제공합니다.

## 렌더링 시스템 {#rendering-system}
LSDE는 텍스트 표시를 사용자 정의하는 "후처리" 렌더링 시스템을 갖추고 있어 읽기와 쓰기를 용이하게 합니다.
텍스트 그룹을 캡처하고 장식을 할당하도록 Regex 패턴을 구성합니다.
이러한 캡처는 번역가, 편집자 또는 LLM에게 추가 정보를 제공하기 위해 변수와 연결될 수 있습니다.
[렌더링 및 패턴 생성에 대한 고급 섹션으로 이동](/ko/features/rendering)

## 헤더 도구 {#header-tools}
1. **후처리 렌더링 활성화/비활성화**
패턴 렌더링을 빠르게 비활성화합니다.
2. **탐색**
다음 및 이전 키 사이를 빠르게 이동하는 버튼입니다.
3. **키 생성**
새 키를 빠르게 생성합니다.
4. **컨텍스트 표시/숨기기**
보기를 단순화하기 위해 키와 관련된 컨텍스트를 표시하거나 숨깁니다.
각 아이콘은 구성된 컨텍스트 레이블에 해당합니다.
5. **언어 표시/숨기기**
동시에 작업할 언어를 필터링합니다.

::: tip 참고
이 필터는 LSDE에서 다른 시스템 작업에도 사용되어 다른 진단 도구에 영향을 미칩니다.
:::

## 편집 영역 {#editing-zones}
이 영역은 활성 언어의 텍스트와 키에 대한 진행 중인 작업을 표시합니다.
6. **트리에서 키 선택**
트리에서 키를 찾아 선택합니다.

::: tip 참고
메타데이터 편집에 유용하며, 활성 키에서만 가능합니다.
:::
7. **작업**
이 키, 해당 관계 및 하위 키에 적용 가능한 작업을 제공하는 메뉴입니다.
8. **보호**
텍스트를 최종 및 보호됨으로 표시하려면 이 확인란을 선택하여 특정 작업 및 작업을 무시합니다.
이 옵션을 비활성화하면 이 키와 관련된 다른 모든 언어의 유효성 검사를 비활성화할 수 있습니다.
0. **키**
키의 전체 경로를 **LSDE 형식**으로 표시합니다.

## 찾기/바꾸기 {#search-replace}
8. **찾기/바꾸기**
[CTRL+F]는 내부 검색 도구를 엽니다.
복잡한 경우를 위한 Regex 모드를 제공합니다.
검색은 컨텍스트 메뉴를 통해서도 시작할 수 있습니다.

## 성능 {#performance}
기본적으로 LSDE는 비활성 창에서 복잡한 렌더링(위젯)을 비활성화합니다.
이는 시각적 경험과 낮은 지연 시간 사이의 좋은 균형을 보장합니다.
성능이 문제가 되지 않는다면 전역 구성에서 이 최적화를 비활성화하십시오.

::: tip 참고
여러 언어가 동시에 표시되면 리소스를 소비할 수 있습니다. 렌더링 시스템은 키별로 분할되어 있습니다.
:::
