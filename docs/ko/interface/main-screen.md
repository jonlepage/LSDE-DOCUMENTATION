# 메인 화면

LSDE 환경은 모듈식 및 고정 가능한 레이아웃 시스템을 제공합니다. 이를 통해 작업 습관에 가장 적합한 위치에 다양한 창을 배치할 수 있습니다. 새 프로젝트를 생성할 때 최적의 탐색 및 작성을 위해 세 개의 창이 미리 배치됩니다.

## 기본 레이아웃 {#basic-layouts}
### 창 이동 및 배치 {#move-and-place-windows}
0. 창을 이동하려면 응용 프로그램 인터페이스의 아무 곳이나 해당 탭을 드래그하십시오.
시각적 제안 시스템이 원하는 위치에 정확하게 재배치하도록 안내합니다.
**창을 표시하거나 복원하는 두 가지 옵션이 있습니다:**
- 상단 탭을 통해 `view => layouts` 메뉴에 액세스합니다.
- 화면 오른쪽 상단에 있는 빠른 버튼을 사용합니다.

::: tip 참고
창 관리 빠른 버튼을 사용하면 창을 즉시 표시하거나 숨기고 마지막 상태로 복원할 수 있습니다.
:::
### 세션 원격 측정 {#session-telemetry}
LSDE는 데이터 및 통계 관리에 관심 있는 사용자들을 만족시킬 풍부한 인터페이스를 제공합니다.
이 정보는 주로 소프트웨어의 바닥글에 표시됩니다.

1. 화면 왼쪽 하단에서 현재 프로젝트 및 세션과 관련된 실시간 원격 측정 데이터를 찾을 수 있습니다.
여기에는 전체 프로젝트에 대한 예상 키, 단어, 글자, 키 입력 및 토큰 수가 포함됩니다.
2. 다음으로 텍스트 편집기의 선택 도구 및 커서에 대한 자세한 정보가 표시됩니다.
3. 특정 요소를 가리키면 추가 정보도 나타납니다.
4. 이 섹션의 오른쪽에 있는 빠른 버튼을 사용하여 언어 모델(LLM)을 활성화 또는 비활성화하고 빠르게 변경할 수 있습니다.

::: tip 참고
마우스 오른쪽 클릭으로 즐겨찾는 모델 간에 전환할 수 있습니다.
:::
5. 세션 중 발생한 경고 및 오류 관련 알림도 전달됩니다.
도움을 받기 위해 이들을 전송할 수 있습니다.
6. 마지막으로 ZEN 모드 활성화 버튼도 이 영역에 있습니다.
