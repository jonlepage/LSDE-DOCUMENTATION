# 설치

[LS-Installer](https://lepasoft.com/ko/software/ls-dialog-editor#download)를 다운로드하려면 운영 체제와 호환되는 버전을 선택하세요. [ZIP](https://wikipedia.org/wiki/ZIP_(file_format)) 형식의 압축 버전을 선택하는 경우, 원하는 폴더에 내용을 압축 해제하세요.

<DocImage src="/doc/lsde/doc-lsde-install-1.webp" />

## LS-INSTALLER란 무엇인가요? {#what-is-lsinstaller}
LS-Installer는 **Lepasoft** 게임 및 소프트웨어 설치를 용이하게 하도록 설계된 **대화형 런처**입니다.
LS Dialog Editor를 설치하려면 사용 가능한 제품 목록에서 선택한 다음 다음 단계를 따르십시오.
1. 이용 약관을 읽고 동의합니다.
2. 설치 디렉토리를 선택합니다.
3. 다운로드를 시작합니다.
4. 원하는 설치 후 옵션을 확인합니다.
5. 바탕 화면의 바로 가기를 통해 또는 설치 폴더에서 직접 애플리케이션을 실행합니다.

::: tip 참고
설치 프로그램은 선택한 제품의 최신 버전을 자동으로 다운로드합니다.
:::

---

## LS-Installer에 문제가 있나요? {#issue-with-lsinstaller}
런처가 실행되지 않는 경우, 소프트웨어 서명에도 불구하고 운영 체제가 실행을 차단할 수 있습니다.
이 경우, 대신 압축 버전을 다운로드하여 자동으로 압축 해제하는 대신 수동으로 압축 해제하십시오.
현재 베타 단계에 있는 **이 소프트웨어는 로컬 서명을 포함**하고 있지만, Microsoft Store에서 유효성을 검사한 서명은 아직 포함하고 있지 않습니다.

::: tip 참고
설치 애플리케이션은 오픈 소스이며 난독화되어 있지 않습니다. 어떤 역컴파일 소프트웨어로도 분해하여 소스 코드를 확인할 수 있습니다.
Microsoft Windows 및 Apple macOS와 같은 운영 체제에서는 유료 인증 서비스를 통해 서명이 검증되지 않은 경우 소프트웨어 차단이 흔합니다. 좋은 평판을 얻은 소프트웨어는 수년간 존재한 후에는 반복적인 인증 비용 없이도 이러한 차단을 피할 수 있습니다.
:::
